# エグザンプル

架空のデータが置かれたフォルダーです。  

参加サークル一覧の取込みを試すには、[きふわらべオンリー即売会_参加サークル一覧.xlsx](きふわらべオンリー即売会_参加サークル一覧.xlsx) を使ってください。GitHub ではリンク先のファイル画面からダウンロードできます。

読込みの手順は、[参加サークルの一覧を取り込む](../Docs/User/GetStarted/Start.md#3-参加サークルの一覧を取り込む) を参照してください。
# 部分受渡しの架空サンプル

- `fictional-proposals.project-portable.json`：A・Cの２案。同じ型IDと、案ごとに説明が異なる同じ定義IDを保持します。
- `fictional-books.project-portable.json`：書籍の入力ルールと明暗の重み。サークル実データを含まず、マル秘の知見として未対応付けで取り込めます。
