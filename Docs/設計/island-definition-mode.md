# 島定義モード実装計画

## 目的

机配置とジャンル配置の間に［島定義］工程を設け、一般参加者評価で使う会場トポロジーを配置案ごとに明示する。

## データ

- 机列は保存せず、向きが同じで長軸方向に隣接する机から自動生成する。
- ［島接続補助直線］は、机列端にある2台の机IDを保存する。座標ではなく机を参照するため、机移動へ追従できる。
- ［向かい合わせ領域矩形］は、通路領域の対角2セルとIDを保存する。
- いずれも `Plan` に属し、配置案の複製時には一緒に複製する。
- 旧JSONでは両リストを省略可能とし、空配列として読み込む。

## 画面と操作

上段モードを［机配置］→［島定義］→［ジャンル配置］→［サークル配置］の順にする。島定義モードの下段には、移動、補助直線追加、向かい合わせ矩形追加、定義削除を置く。

- 自動机列：机中央を通る青緑色の太線で表示する。
- 補助直線：机を2回クリックし、橙色の線で端同士を接続する。選択中はマウスまでプレビューする。
- 向かい合わせ領域：対角セルを2回クリックし、半透明の紫色矩形で表示する。
- 削除：補助直線の端の机、または矩形内をクリックして対象を削除する。

## 判定と保守

初版では同一向き・同一幅で長軸方向に接する机を同じ机列とする。補助直線を加えた接続グラフから島を求め、閉路なら環状、端が残れば直線状と判定できるようにする。向かい合わせ矩形の対向辺に面する机列の評価接続は次段階で `GeneralAttendeeEvaluator` に組み込む。

机の編集後は机列を再計算する。参照先を失った補助直線や、対面する机列がなくなった矩形は画面上で警告対象とし、利用者が削除または再設定できる構造にする。

## 実施順

1. Coreモデル、JSON保存・読込、検証
2. 机列自動検出
3. Application編集コマンドとUndo/Redo
4. 島定義モードのツールバー、描画、二点クリック操作
5. 自動テストと既存ファイル互換確認
6. 島・環状・向かい合わせを用いた一般参加者評価への置換

## 一般参加者評価への接続

机列内、同じ机内、島接続補助直線で直接隣り合う採点セルを同一ジャンルの連続区間として数える。補助直線で環が閉じていれば先頭と末尾も隣接するため、環状の分断規則が通常のグラフ連結判定で成立する。

向かい合わせ領域はセル単位の全単射として扱う。左右の対向辺では同じ行、上下の対向辺では同じ列にあるセルだけを一対一で対応させ、斜めのセルは対応させない。さらに、各セルを含む机の島側が通路と反対側を向き、一般参加者側が通路へ面していることを必要条件とする。対応する両セル上の同ジャンル区間は一つの群へ統合し、統合1回につき暫定係数 `0.7` を掛ける。評価計算に入れる前に、それぞれのセル対が水平・垂直・机方向の条件を満たすか個別判定する。

```text
ジャンル評価 = 配置サークル数 × (1/2)^(最終群数-1) × 0.7^(向かい合わせ統合数)
一般参加者評価値 = 各ジャンル評価の合計
```

このトポロジーは一般参加者評価だけが参照する。サークル参加者評価は従来どおりサークル属性と重みマップから独立して算出する。ただし、承認済み合体サークルの同一机必須条件は両評価に適用する。

## 分析表示

ジャンル配置とサークル配置には、初期状態オフの［分析］切替ボタンを置く。オンの場合だけ、島内で同ジャンルが直接連続する区間を暗い縁取り付きの緑色太線、異なる島が向かい合わせで統合される箇所を緑色の細い四辺形で表示する。配置作業時はオフにして、評価根拠を確認するときだけオンにできる。
