# ジャンル配置モードと非公開プロジェクト表示の実装計画

## 目的

配置作業を［机配置］、［ジャンル配置］、［サークル配置］の三段階として画面に表し、一般参加者向け評価とサークル参加者向け評価を区別する。また、外部公開してはいけないイベントプロジェクトを、作業者が画面上で継続的に判別できるようにする。

業務上の評価方針は [むずでょのまとめ](../むずでょのまとめ.md) を正本とする。

## 実装方針

### 三つの編集モード

ツールバーを二段に分ける。

- 上段には［机配置］［ジャンル配置］［サークル配置］を常時表示する。
- 下段には、配置案切替、Undo/Redo、保存などの共通操作と、選択中のモードで使用する操作を表示する。
- 机配置ではサークル石を隠す。
- ジャンル配置では、配置済みサークルのジャンル色を強調して表示し、カラータイルをドラッグ＆ドロップしてサークルを配置できるようにする。下段の［サークル一覧ファイル読取］からジャンルIDを更新できるようにする。
- ジャンル配置でも合体サークル間の接続線を表示し、泣き別れを目視確認できるようにする。
- 2スペースを使用する単一サークルも、2枚のカラータイルを接続線で結び、一体としてドラッグされることを示す。
- 合体サークルを別の机上のサークルへドロップした場合は、合体した2サークルと移動先の机上の全サークルを1回の操作で交換する。片方だけを交換して合体条件を一時的に破らない。
- 単独の2スペースサークルを別の机上へドロップした場合も、移動先の机上の全サークルと2セル単位で交換する。
- ジャンル配置ではジャンル色との混同を避けるため、机のゴールドオーカー色を使わない。机は無彩色の太いワイヤーフレームと向き印で表し、通常の格子線は交点ドットに替える。カラータイルの枠線は交点ドットと同じ色の細線にする。
- 参加サークル全体のジャンル構成を円グラフで表示し、最大ジャンルとサークル数を併記する。円グラフの扇形と凡例にも、会場タイルと同じ主色・副色・網掛けを反映する。
- サークル配置では、ジャンル色の上にサークル石を表示し、割当て、解除、交換を行う。

ジャンル配置の初版では、独立したジャンル枠を保存しない。サークルデータの `genreId` と配置済みサークルの位置から色分けを生成する。将来、サークルを置く前にジャンル枠だけを編集する必要が生じた場合は、配置案にジャンル領域を追加する。

### ジャンルデータ

参加サークルに任意の `genreId` を追加する。JSON、Excelブリッジ、アプリ内のExcel／CSV取込みで値を維持する。ジャンルIDがないサークルは中立色で表示し、一般参加者評価値のジャンル集計には含めない。

ジャンルIDを文字順に並べ、赤、黄、黄緑、緑、水色、青緑、青、藍色、青紫、赤紫、桃色、茶色の固定12色を順番に割り当てる。13ジャンル目以降は同じ色列を繰り返し、横縞、太縦縞、太い格子、市松模様、細い格子、均等横縞、水玉などの網掛けパターンを重ねる。均等横縞は主色帯と副色帯を同じ太さで交互に描く。市松模様はチェス盤のように主色と副色の正方形を縦横交互に配置する。同じプロジェクトを開き直しても同じジャンルが同じ色とパターンになり、設定を別途保存する必要はない。

ジャンル配置ツールバーの［ジャンル表示設定］ボタンから対応表ダイアログを開き、各ジャンルの［主色］［副色］［網掛け］を変更できる。網掛け候補は黒を主色、白を副色とした文字見本付き一覧で表示する。パターン名の括弧内は（主色の太さ・副色の太さ）の順とし、［（太細）横縞］［（太細）縦縞］［（太細）格子］［（均等）横縞］のように表記する。変更内容はプロジェクトJSONの `genreStyles` に保存し、未設定のジャンルには上記の自動割当てを使用する。

［単色］では副色を使用しないため、副色セルをコントロール背景色でグレーアウトし、内容とドロップダウンを隠して編集不可にする。別の網掛けへ変更すると副色セルを再表示する。非表示中も値は保持する。

### 二つの評価値

- ［一般参加者評価値］はジャンルのまとまりを評価する。
- ［サークル参加者評価値］は、従来の評価機能が計算していた特徴量別の重み付き合計を引き継ぐ。
- 配置案は、一般参加者評価値の降順、その同点内でサークル参加者評価値の降順に並べる。

配置案一覧の表示順は編集モードに合わせる。机配置モードでは評価値を表示せず、配置案名の昇順とする。ジャンル配置およびサークル配置モードでは、一般参加者評価値の降順、その同点内でサークル参加者評価値の降順とする。前・次ボタンと `Tab` による切替も、画面に表示中の順序に従う。

初版の一般参加者評価では、同じジャンルの配置済みサークルの採点セルが上下左右に隣接していれば一つの連続群とする。ジャンル内の配置済みサークル数を `n`、連続群数を `k` としたとき、ジャンル評価を次のように計算する。

```text
ジャンル評価 = n × (1/2)^(k-1)
一般参加者評価値 = 各ジャンル評価の合計
```

合体サークルは、相手のジャンルにも所属するものとして集計する。

承認済みの合体サークルは配置上の必須条件として扱う。組になった二つのサークルが両方とも同じ物理机に配置されていない案は、一般参加者評価値とサークル参加者評価値をともに0点とする。違反時は接続線を赤くし、配置案一覧とステータスにも合体違反を表示する。

この計算は島定義トポロジーを利用する。机列・島接続補助直線による連続区間を数え、向かい合わせ領域を介した群の統合には暫定係数 `0.7` を適用する。島定義は一般参加者評価だけに影響し、サークル参加者評価の重み計算には影響しない。

### マル秘フラグ

プロジェクトメタデータに任意の真偽値 `isConfidential` を追加する。省略時は `false` として旧ファイルを読み込めるようにする。

`true` の場合は次を表示する。

- ウィンドウタイトルのイベント名直前に `（秘）`
- 画面右上に赤い `秘 SECRET` バッジ

フラグは、イベントプロジェクトの新規作成時に設定できる。また、アプリケーション起動時のイベント選択画面から、既存プロジェクトをあとから［マル秘］に設定できる。設定操作の前には、アプリから解除できないことと、解除にはJSONの直接編集が必要であることを表示する。事故防止のため、アプリ内には `true` から `false` へ戻す操作を設けない。

このフラグは注意喚起だけを目的とし、暗号化、アクセス制御、保存・コピー・スクリーンショットの禁止は行わない。

## 引き継ぎ事項

次の拡張候補は、机の並びを単なるセル隣接ではなく、直線状の島、環状の島、向かい合わせとして認識する会場トポロジーの導入である。その際は `GeneralAttendeeEvaluator` の連続群判定を差し替え、[むずでょのまとめ](../むずでょのまとめ.md) にある切断・分断規則と向かい合わせ係数を適用する。

また、サークル未配置の段階でジャンル計画を作る必要が明確になった場合は、`Plan` にセル単位または机区間単位のジャンル割当てを追加し、現在の「サークル配置から派生する色」を初期値として利用する。
