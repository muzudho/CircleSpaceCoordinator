# 続きはここから

`Ctrl + P`で現在のGUIを`ピクチャー/CircleSpaceCoordinator/Screenshots`へPNG保存します。撮影後に0.42秒のフラッシュ・シャッター幕と動的生成したシャッター音を再生し、保存PNGには撮影後エフェクトを含めません。

`Ctrl + S`またはフロッピーディスクボタンで編集中のJSONを保存します。明示的に開いたJSONは同じファイルへ、引数なしの架空サンプルは`ドキュメント/CircleSpaceCoordinator/Projects/fictional-working-copy.json`へ保存します。一時ファイルを完成させてから置換し、サンプル原本は上書きしません。

右側の配置案一覧は評価値の降順で、選択行を強調し、評価値を相対バーで比較します。行クリック、前／次ボタン、`Tab`で案を切り替えます。Duplicateボタンは現在案の机・割当てを複製して「配置修正 N」案を作り、その案を選択します。

## 判断済みの方針

- アプリ本体と評価計算はC#を正本にする。
- Pythonは削除せず、openpyxlによるExcel import/exportに限定して残す。
- 参加者一覧の交換にはCSVも利用可能。
- 会場と複数案を含む正規保存形式には、`schemaVersion` 付きJSONを使う。
- KifuwarabeGo2026のIME対応UIは、囲碁固有の名前空間を外して後から移植する。
- Windows固有IME処理は `StationeryUI` ではなく `Desktop` 側へ置く。
