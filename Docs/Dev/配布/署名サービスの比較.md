# 署名サービスの比較

確認日：2026-09-06。申請・契約・署名サービスの実機検証は行っていません。

## 採用判断

無料 OSS の継続配布にあたり、有料サービスへの依存と将来の値上げを避ける方針です。短時間で修正して再配布できることも必要です。有料方式は調査記録として残し、現時点では採用しません。ソース配布の制限は [別紙](ソース配布とSmart%20App%20Control.md) を参照してください。

## SignPath Foundation

条件を満たす OSS 向けの無料サービスです。秘密鍵はサービス側にあり、証明書は Foundation 名義です。[公式説明](https://signpath.org/)

主な条件は、OSI 承認ライセンス、商用デュアルライセンスや非公開独自コンポーネントの制限、保守・リリース実績、機能説明、プライバシー等の要件、多要素認証、担当者と Code signing policy の公開、製品メタデータの設定、検証可能なビルドです。採用は個別審査で、条件ページには Draft と表示されています。

**初回の Foundation による採用審査と、毎回のプロジェクト担当者による署名承認は別です。** 毎回 Foundation 職員がコードを人的審査するという意味ではありません。

署名対象は原則、自分たちが開発・保守するソース由来のバイナリです。`CircleSpaceCoordinator.*` は候補ですが、SDL2、MonoGame、ClosedXML、.NET ランタイム等をこのプロジェクトの無料枠で一括署名することはできません。未署名の外部 OSS バイナリの同梱自体は認められています。[公式条件](https://signpath.org/terms.html)

GitHub Actions で利用する場合は、署名依頼までの全ジョブを GitHub-hosted runner で実行し、成果物を Actions に保存します。公式 Action で依頼し、承認後の成果物を取得します。ローカルビルドのアップロードだけではこの条件を満たしません。[公式 GitHub 連携](https://docs.signpath.io/trusted-build-systems/github)

導入する場合の流れは、公開ソース → CI ビルド・テスト → 配布内容検査 → 成果物アップロード → 署名依頼 → 担当者承認 → 署名済み成果物取得 → 検証・ZIP 化 → 展開・動作確認 → 公開です。現在の `New-ReleaseZip.ps1` は再ビルドと自己署名を行うので、そのまま署名済み成果物に適用する構成にはしません。

外部 DLL を含む全ファイルの署名をこのサービスだけで完結できないため、現時点では導入を進めません。

## 有料方式（現時点では採用しない）

| 方式 | 通常のリリース時の操作 | 制約・確認事項 |
| --- | --- | --- |
| 個人向け証明書＋USB トークン | 手元の PC で SignTool を実行 | 初回本人確認・機器準備、個人名の公開、証明書更新費用 |
| 個人向け証明書＋SSL.com eSigner | 手元の PC や CI からクラウド署名 | 証明書代とサービス利用料、署名回数、通信・サービス稼働に依存 |
| Microsoft Artifact Signing | PC や CI からクラウド署名 | 日本の組織は対象地域に含まれるが、日本在住の個人は Public Trust の対象外 |

SSL.com は法人登記不要の IV 証明書を提供し、確認済み個人名が署名に表示されます。商品ページでは証明書1年 US$129、USB トークン US$379 と表示されました。別の公式ページにはトークン US$249 の表示もあり、最終価格、日本向けの発行・配送条件は未確定です。[IV 商品ページ](https://www.ssl.com/products/software-integrity/code-signing/iv/)

eSigner は SignTool 連携と自動署名に対応します。月額換算 US$15 の表示がありましたが、支払期間・署名回数枠を含めた見積もりが必要です。ZIP の配布回数と、中の各 EXE・DLL への署名回数を混同しないでください。[eSigner 仕様・料金](https://www.ssl.com/products/software-integrity/signing-service/)

Microsoft Artifact Signing の Basic は月 US$9.99、5,000署名までという説明です。申請できる組織かどうかは地域だけで確定しません。[料金](https://learn.microsoft.com/en-us/azure/artifact-signing/how-to-change-sku)、[利用資格](https://learn.microsoft.com/en-us/azure/artifact-signing/quickstart)

これらは初回の本人・組織確認後、通常の署名操作で毎回認証局担当者のリリース審査を待つ方式ではありません。実際の処理時間はファイル数・認証設定・通信等に依存します。[ローカル署名手順](https://www.ssl.com/how-to/using-your-code-signing-certificate/amp/)

有料証明書でも外部 DLL を無条件に署名できるとは判断しません。提供元の有効な署名を維持し、未署名の外部バイナリについては配布・署名の権利と証明書契約を初回導入時に確認する必要があります。
