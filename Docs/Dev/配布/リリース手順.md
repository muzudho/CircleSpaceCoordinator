# リリース手順

2026-09-26 更新。Smart App Control をオフにする運用に合わせ、自己署名とビルド前の `bin`・`obj` 削除を廃止した。旧手順は[廃止記録](../Archive/RetiredSmartAppControl/README.md)に保存している。

Windows と .NET 10 SDK を使用し、リポジトリーのルートで実行する。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Packaging\New-ReleaseZip.ps1
```

Desktop アプリと２つの CLI を新しい publish フォルダーへ発行する。Desktop には .NET ランタイムと編集・思考エンジンを同梱する。配布内容検査に通った Desktop フォルダーを `artifacts/release/` の ZIP に収める。出力された `ZipPath` と `Version` を確認し、展開したアプリの起動を確認する。既存の publish フォルダーと ZIP は上書きしない。

配布内容検査は、必要な実行ファイル・エンジンと許可された付属ファイルを確認する。署名処理は行わない。必要なら `-RuntimeIdentifier win-x64` と `-ZipPath` を指定できる。ZIP を作らず発行だけ行う場合は `scripts/Packaging/Publish.ps1` を使う。

公開前には[情報点検と残作業](../public-release-review.md)を確認する。
