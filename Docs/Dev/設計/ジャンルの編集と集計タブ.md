# ジャンルの編集と集計タブ

メインメニューの［プロジェクト］の右隣に［ジャンル］を置く。既存のジャンル対応表とジャンルデータの入口を、同じページの４つのタブに統合する。メニューから各タブを直接開くこともできる。

| タブ | 内容 |
| --- | --- |
| ジャンルコードと色網掛け | 主色・副色・網掛け・ジャンル別コメントの編集 |
| カタログ | 同じ大きさの色・網掛け見本を３列で比較。１ページ18ジャンル |
| スペース数比率 | 全ジャンルの必要スペース数を、合計100%の積み上げ横棒で比較 |
| 円グラフ | 同じ集計を色・網掛け付きの円グラフで比較 |

集計値はサークルの `RequiredCellCount` の合計。配置済みかどうかによらず集計し、サークル数も別途保持する。ジャンル未設定は「（未設定）」として含める。設定だけ残っているジャンルは０スペースの見本として表示する。スペース合計が０ならグラフは描かず、その理由を表示する。

カタログと凡例は前後ボタン・PageUp/PageDown・マウスホイールでページ送りする。グラフは凡例のページにかかわらず全ジャンルを描く。横棒・円グラフにマウスを合わせると、共通の画面下ツールヒント欄にジャンル名、スペース数、割合、サークル数を表示する。

全タブで同じ編集ドラフト・全体コメント・変更タグを共有する。色の変更は切り替え先の見本にも反映する。タブ切り替えだけでは変更を確定せず、変更ありの［閉じる］ではチェンジログを要求する。［破棄］ではページを開いたときの状態に戻す。閲覧だけでは変更タグを更新しない。
