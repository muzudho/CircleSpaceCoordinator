# ジャンルの編集と集計タブ

メインメニューの［プロジェクト］の右隣に［ジャンル］を置く。クリックすると一体化ページへ直接移り、最初は［色網掛け］を表示する。タイトル行は「ジャンル｜［色網掛け］［色見本カタログ］［スペース数比率］［円グラフ］｜［サークルデータ順］［スペース数順］」の順にまとめ、全体コメント欄と重ならないようにする。

| タブ | 内容 |
| --- | --- |
| 色網掛け | 太線色・細線色・網掛け・ジャンル別コメントの編集 |
| 色見本カタログ | 全ジャンルの色・網掛け見本を１画面にタイル配置。文字ラベルなし、件数に合わせて列数・大きさを調整 |
| スペース数比率 | 全ジャンルの必要スペース数を、合計100%の積み上げ横棒で比較 |
| 円グラフ | 同じ集計を色・網掛け付きの円グラフで比較 |

集計値はサークルの `RequiredCellCount` の合計。配置済みかどうかによらず集計し、サークル数も別途保持する。ジャンル未設定は「（未設定）」として含める。設定だけ残っているジャンルは０スペースの見本として表示する。スペース合計が０ならグラフは描かず、その理由を表示する。

カタログはページ送りせず、全見本を同時に比較する。名前と件数は見本にマウスを合わせたときに画面下へ表示する。グラフの凡例は前後ボタン・PageUp/PageDown・マウスホイールでページ送りする。グラフは凡例のページにかかわらず全ジャンルを描く。横棒・円グラフにマウスを合わせると、共通の画面下ツールヒント欄にジャンル名、スペース数、割合、サークル数を表示する。

円グラフには［画面いっぱいに表示］を置く。拡大中は作業者欄、復帰ボタン、ツールヒント欄を残し、アプリケーション画面の残りの領域いっぱいに円を描く。［元のサイズに戻す］またはEscで通常表示へ戻り、編集内容は保持する。

全タブで同じ編集ドラフト・全体コメント・変更タグを共有する。色の変更は切り替え先の見本にも反映する。タブ切り替えだけでは変更を確定せず、変更ありの［閉じる］ではチェンジログを要求する。［破棄］ではページを開いたときの状態に戻す。閲覧だけでは変更タグを更新しない。

色網掛けの一覧は１ページ６行で固定する。前後ボタン・PageUp/PageDown・マウスホイールはページ単位で移動し、最終ページの余白を前ページの行で埋めない。矢印キーの行移動とカタログからのジャンプでも、対象行を含む６行区切りのページを表示する。

カタログとスペース数比率には［サークルデータ］［スペース数］［ジャンルコード］の並び替えボタンを置く。サークルデータ順は参加者データに現れる順、スペース数順は必要スペース数の降順、ジャンルコード順は手入力したカンマ区切りの順。同じ値や未入力コードはジャンルコード順で安定させる。ジャンルコード順の初回選択時に入力欄を開き、入力した順を以後の表示に使う。円グラフは常にスペース数順で描き、選択中の並び替えには影響されない。

ジャンルが単色のとき、細線色セルは未使用なので背景・枠線・文字を描かず空白にする。クリック対象にもせず、色の選択は太線色セルから行う。

［色網掛け］と［色見本カタログ］は操作対象のジャンルを共有する。カタログのタイルをクリックすると［色網掛け］へ切り替え、対象行が見える位置まで移動する。ジャンル名のクリックでも操作対象を選べる。対象行全体と対応するタイルには既存の操作対象色（水色）の枠を表示し、タブを往復しても選択を保持する。選択だけでは編集扱いにしない。

編集表の下には［新規作成］［反対側へコピー］［削除］をこの順で同じ行の左端に並べる。左右どちらの表でも操作対象に適用する。新規作成は現在の表示順で対象行の直前に挿入し、水色の操作対象枠は同じ表示位置で新しい行を指す。名前は「新しいジャンルコード」、重複時は「新しいジャンルコード_2」「新しいジャンルコード_3」など最初の空き番号とし、初期値は白の単色・細線色は黒・コメントなし。挿入位置を保持するため、その並びをジャンルコード順として保存する。

対象未選択なら表示範囲の先頭に作成する。空のパッケージ表は一覧領域をクリックして作成先に選べる。削除は対象行を表から除き、次の行（末尾なら前の行）を操作対象にする。最後の行を削除した場合も、同じ側に新規作成できる。参加サークルのジャンル値は変更しない。行の追加・削除も既存の自動保存と変更コメントの対象とする。

［反対側へコピー］が成功したら、コピー先の行へ操作対象を移し、水色の枠を表示する。表示範囲外ならその行が見える位置までスクロールする。新規行・上書き・名前を変えてコピーのいずれも同じ動作とし、キャンセルでは選択を変更しない。

サークルが０件でも色設定があるジャンルは編集一覧に含める。「（未設定）」はジャンルコードを持たない集計枠のため、タイルの選択のみ行い、編集行へは移動しない。その理由は画面下のツールヒントに表示する。

網掛けは従来の８種類に、右肩上がり斜線・右肩下がり斜線・斜め格子の等幅／太細と、斜め市松模様の「ダイヤ」を加えた15種類。新しい斜線は16単位周期で副色の幅を等幅８・太細３とし、斜め格子は２方向の斜線を重ねる。ダイヤは斜め座標で市松を描く。矩形見本・丸い駒・円グラフで共通の模様判定を使う。

構図での呼び名は、[Karen Halbert氏の解説](https://www.karenhalbert.com/artdetails.cfm?id=1383)を参考に、右肩上がりを「バロック・ダイアゴナル」、右肩下がりを「シニスター・ダイアゴナル」としてツールヒントに併記する。

斜め格子は等幅・太細ともに初版から黒白の割り当てを反転する。２方向の線が重なる部分を太線色、線の間を細線色で描き、保存済みの斜め格子にも適用する。

細線色は不透明度255で描き、太線色との半透明合成で色が変わらないようにする。配色見本・カタログ・配置図・円グラフで選択した色をそのまま使用する。

色の画面表示名は「太線色」「細線色」とする（保存項目は従来のPrimaryColor／SecondaryColorを継続）。白黒見本では黒＝太線色、白＝細線色。等幅やダイヤでは両色の面積が同じになる。ダイヤの色の割り当ては初版から反転し、保存済みのダイヤも新しい割り当てで描画する。網掛け選択ボタンの名前は17ポイント相当とし、ボタン高さの比率で縮めず、文字領域に26単位の高さを確保する。
