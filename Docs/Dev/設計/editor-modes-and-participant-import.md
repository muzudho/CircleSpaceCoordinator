# 編集モードと参加サークル取込みの実装計画

## 目的

会場そのものを編集する操作と、参加サークルを机へ割り当てる操作を分離し、作業中に不要なボタンや駒を表示しない。参加サークル一覧は Excel（`.xlsx`）または CSV からアプリへ直接取り込み、Python や Microsoft Excel のインストールを必要としない構成にする。

## 用語とID

- **内部ID (`id`)**: アプリ内の参照整合性に使用する変更されにくいID。画面上の連番とは別物。
- **サークルID (`circleId`)**: 主催者から渡される任意の文字列。例: `ABC1234`。イベント内で重複不可。
- **サークル名 (`displayName`)**: 画面に表示する名称。例: `ぐれーすけーる`。同名を禁止しない。
- **石番号**: 現在の参加サークル順を人が識別するための `1..n`。永続IDには使わない。

既存JSONとの互換性を保つため、古いデータに `circleId` がない場合は内部IDをサークルIDとして読み込む。

## 編集モード

### 机配置モード

- 会場サイズ変更
- 机の追加、移動、削除、自動配置、回転
- 机の向き、NEXT表示、配置ゴースト
- サークル石と割当て表示は隠す

### サークル配置モード

- 参加サークル一覧の取込み
- 未配置の石を机のないセルへ並べる
- 石の選択、机への割当て、割当て解除
- 机配置専用のボタンは隠す

配置案切替、Undo、Redo、配置案複製、ファイル読込み・保存、スクリーンショットは両モード共通とする。モード切替時はツールバーを組み直す。

## Excel／CSV取込み

取込みの動作確認には、架空の [きふわらべオンリー即売会_参加サークル一覧.xlsx](../../../examples/きふわらべオンリー即売会_参加サークル一覧.xlsx) を使える。

Excel読込みには MIT ライセンスの `ClosedXML` を使用する。取込み処理は `Infrastructure`、プロジェクト更新規則は `Application`、ファイル選択と列対応画面は `Desktop` に置く。

1. `.xlsx` ではシートを選択する。CSVは単一シート相当として扱う。
2. 先頭の非空行を列見出しとして読み取る。
3. サークルID列、サークル名列、必要セル数列（任意）、合体先サークルID列（任意）を選択する。
4. 取込み前に先頭行をプレビューする。
5. 空のサークルID、サークルID重複、不正な必要セル数をエラーとして拒否する。
6. 同じサークルIDの既存参加者は内部IDを維持して更新する。
7. 一覧から消えた参加者を削除し、その参加者の全配置案の割当ても削除する。
8. 未指定の必要セル数は1とする。
9. 合体先サークルIDは同じ一覧に存在する必要があり、自分自身は指定できない。対応する石はペアとして隣接・連結表示する。

初期実装では未使用列を無視する。評価値、タグ、出力列を含む任意列マッピングは、この取込み境界を拡張して追加する。

## 業務情報とログ

実際のExcel、CSV、イベントJSON、操作ログは業務情報を含み得るため、公開リポジトリへ追加しない。リポジトリには架空データだけを置く。操作ログには内部ID、サークルID、サークル名を記録してよいが、ログ自体を業務データとして扱う。

- 取込み後の石数が参加サークル数と一致する。
