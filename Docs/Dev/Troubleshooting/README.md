# トラブルシューティング

開発・実行中に起きた問題と、調査結果、当面の対処方法をここに蓄積します。

| 問題 | 現在の状況 |
| --- | --- |
| [Smart App Control による起動ブロック](Smart%20App%20Controlによる起動ブロック.md) | Visual Studio の再起動後に F5 起動成功の報告あり。既存の開発用自己署名を維持して作業を継続。根本原因は未特定 |

## 記録するとき

問題ごとに Markdown ファイルを作り、次の内容を残します。

- 記録日、発生環境、対象バージョン・コミット
- 症状とエラーメッセージ
- 確認できた事実、本人からの報告、推測の区別
- 実施した対処と結果、今どう作業を続けているか
- 未解決事項、再発時の確認手順、関連資料

後から起動できた場合も経緯を追記し、一度の成功を恒久的な解決と取り違えないようにします。公開するログには個人情報や実際の参加者データを含めません。
