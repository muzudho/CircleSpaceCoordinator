# 一般公開に向けた情報点検（2026-09-06）

現時点では、このリポジトリと履歴をそのまま一般公開できるとは判断していません。公開範囲は未確定のため、ソースと実行ファイルの両方を対象に初回点検しました。

## 公開前に分離・確認するもの

| 対象 | 確認結果と対応 |
| --- | --- |
| `Docs/Dev/素材/` のExcel 2件・ZIP 2件 | Git管理下。Excelには作成者などのOfficeメタデータが存在。内容の個別公開可否は未判定のため、公開対象から外す。ZIP内のExcelも対象。 |
| `Docs/` 内の個人用メモ2件 | Git管理下。会話・運用背景・ローカルユーザーパスを含み得る。公開用説明は別途書き起こす。 |
| `application-settings.json` | 現在の追跡ファイルにはschemaVersion以外の利用データは入っていない。ただし実行時には利用履歴やパスを記録するため配布から除外する。 |
| Git履歴 | 128コミットから到達できるファイルを点検し、129個の過去のファイル内容に要確認の分類が付いた。これは129件の漏洩を意味せず、同じ文書の過去版も含む。現在のファイルを消すだけでは履歴から消えない。作者名・メール・コミットメッセージも別途公開可否を確認する。 |
| 操作ログ・スクリーンショット・利用後の配布フォルダー | 旧ログには実名等やパスが記録され得る。画像には画面上の情報が残る。開発・業務利用したフォルダーをそのままZIP化しない。 |
| 署名済みバイナリ | 証明書のSubject等に何を公開するか確認する。署名成功だけでは内容や個人情報の点検にはならない。 |

## 今回の対策

- 操作ログの保存時に自由記述の `detail` を除去。操作名・時刻・座標・成否は記録する。既存ログを消去・匿名化する変更ではない。
- Excel・ZIP・ローカル設定・JSONLログ・秘密鍵用の拡張子などを `.gitignore` に追加。既に追跡中のファイルと過去履歴には効かない。
- 設定ファイルに `CopyToOutputDirectory=Never` と `CopyToPublishDirectory=Never` を明示。
- `New-ReleaseZip.ps1` でZIP化前の内容点検を必須化。実行に必要なバイナリ、指定されたランタイムJSON、アイコン、リポジトリと一致する架空サンプル以外は拒否する。
- ローカル点検スクリプト `scripts/audit_public_content.py` を追加。検出値を表示せず、ファイルの場所と分類を `artifacts/privacy-audit/report.json` に保存する。報告書自体も公開物には含めない。

## 次の公開準備

ソースを公開する場合は、現在の開発リポジトリを非公開のまま保ち、レビューしたソース・架空サンプル・公開用ドキュメントだけを新しい履歴へ取り出す方法を推奨します。今のリポジトリの公開設定変更、履歴改変、ファイル削除、外部へのアップロードは今回行っていません。

実行ファイルを公開する場合は、空の出力先へのRelease発行 → 配布内容の点検 → 署名情報の確認 → 別フォルダーへの展開・起動確認 → 公開、の順で進めます。公開ZIP候補はまだ作成していません。

点検は特定の秘密鍵・トークン形式、メール候補、ユーザーパス、Officeメタデータ、注意対象のファイル種別を調べる一次検査です。人名・住所・業務上の非公開事項をすべて判定するものではありません。入れ子の圧縮ファイル、任意のバイナリ、画像、署名情報は個別確認が残ります。
