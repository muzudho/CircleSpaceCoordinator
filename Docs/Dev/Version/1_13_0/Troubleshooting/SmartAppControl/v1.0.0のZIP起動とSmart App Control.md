# v1.0.0 の ZIP 起動と Smart App Control

記録日：2026-09-06

## 起動できたという報告

開発者本人から、GitHub のリリースページで ZIP をダウンロードし、展開して `CircleSpaceCoordinator.Desktop.exe` を実行したところ、Smart App Control（SAC）にブロックされず起動できたという報告がありました。

対象は [v1.0.0](https://github.com/muzudho/CircleSpaceCoordinator/releases/tag/v1.0.0) に添付した `CircleSpaceCoordinator.Desktop-v1.0.0-win-x64.zip` です。.NET 10.0.11 ランタイムと必要な DLL を含む Windows x64 向け配布物です。

**未署名のファイルを含む ZIP でも、SAC にブロックされず実行できる場合があります。** 今回の報告は、この配布方法を利用できた一例として記録します。

## 確認できた事実と範囲

| 項目 | 確認結果 |
| --- | --- |
| GitHub から取得した ZIP の起動 | 本人から起動成功の報告あり。ダウンロード・展開操作自体をエージェントが観察したものではない |
| 調査時のこの PC の SAC 設定 | `HKLM\SYSTEM\CurrentControlSet\Control\CI\Policy` の `VerifiedAndReputablePolicyState` は `1`（オン） |
| 配布元 EXE の署名 | ローカルに保管した配布用 EXE は `Get-AuthenticodeSignature` で `NotSigned` |
| 配布物全体の署名 | 作成時の検査では EXE・DLL 計284個のうち268個が `Valid`、16個が `NotSigned` |
| 署名の追加 | 公的なコード署名・開発用自己署名は追加していない。提供元の既存署名は保持している |
| 直近のブロック記録 | 同日19:28:58、`CircleSpaceCoordinator.Desktop.Tests.dll` を OriginalFileName とするバイナリに、イベント ID 3077、ポリシー名 `VerifiedAndReputableDesktop` の記録あり。今回の配布 EXE の許可理由を示す記録ではない |
| 有効なポリシー一覧 | `citool.exe -lp -json` はアクセス拒否となり取得できなかった。レジストリーの設定値と、実際に適用中のポリシー一覧を同一視しない |
| 今回の起動が許可された理由 | 直接示すログやクラウドの判定結果は取得できていない |

調査では Windows の保護設定や証明書の信頼設定を変更していません。本人がダウンロードした展開先のファイルは、今回の調査では直接検査していません。

配布 ZIP はソースのコミット `afff5704ab4ed42187fcc99e22e65bd91a7d5bca` から作成しました。アップロード後に GitHub 側のダイジェストとの一致を確認した SHA-256 は次のとおりです。

```text
618ea6e8f3612ea7422d54c783af1db4016e33e92ac903e18775b98bf09d0b48
```

## 未署名でも許可され得る理由

Microsoft の説明では、SAC はまずクラウドのセキュリティサービスによる安全性判定を利用します。安全と判断できれば実行を許可し、悪意がある・望ましくないと判断すればブロックします。安全性を十分に判断できない場合に署名を確認し、信頼できる署名もなければブロックします。[Microsoft：SAC FAQ](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

したがって、**「未署名なら必ずブロックされる」という説明は正確ではありません。** 「安全性の判定で許可されず、信頼された署名もない場合にブロックされ得る」と説明します。

今回の設定値と起動報告からは、単に SAC がオフだったと決めつけるよりも、配布ファイルが安全性判定によって許可された可能性が考えられます。ただし、これは公式の仕組みから考えられる仮説であり、この起動について原因を特定した結果ではありません。

GitHub が EXE に署名を追加した、開発用自己署名が効いた、GitHub で公開すれば必ず信頼される、と判断する根拠もありません。

## 配布案内への反映

ZIP 配布は利用可能な選択肢として残します。ソース配布も併せて提供します。利用者には、例えば次のように案内します。

> v1.0.0 の Windows x64 用 ZIP は、開発者の PC で GitHub からダウンロード・展開後に起動できた報告があります。未署名の EXE・DLL を含むため、Smart App Control が有効な環境でブロックされる場合もあります。

今回の成功だけで、他の PC・次のバージョン・全ての機能でも許可されるとは保証しません。後から読み込まれる DLL もあるため、起動成功と全機能の動作確認は区別します。[Microsoft：SAC でのテスト](https://github.com/MicrosoftDocs/windows-dev-docs/blob/docs/hub/apps/develop/smart-app-control/test-your-app-with-smart-app-control.md)

今後追加で確認するときは、アプリの版と ZIP のハッシュ、Windows のバージョン、SAC の状態、試した操作、許可・ブロックされたファイルを記録します。設定変更を伴う検証と、通常状態での検証も区別してください。
