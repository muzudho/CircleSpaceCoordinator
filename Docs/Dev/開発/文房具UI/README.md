# 文房具 UI への移行

Discord のウィンドウ共有中にも、入力・確認・進捗などを同じアプリ画面で見せるための調査・実装記録です。

- [調査結果と実装計画](調査結果と実装計画.md)
- [ボタンの試験導入](ボタンの試験導入.md)
- [移行進捗と次の作業](移行進捗.md)

ツールバーに続き、配置の削除確認と、自動最適化の時間指定・進捗・結果通知を画面内へ移行しました。文字入力、一覧・表編集、ファイル選択などは Windows フォームが残っています。実装済みと実機確認済みを分けて [進捗表](移行進捗.md) で管理します。
