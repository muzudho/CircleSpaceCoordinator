# 開発日誌

## 2026-09-06 夜：v1.0.1

画面共有で操作を追いやすくするため、文房具 UI への移行を進めた。

- Windows 用実行プロジェクトを `CircleSpaceCoordinator.Desktop.Windows` に改名し、OS 非依存の操作・保存・ログ等を `CircleSpaceCoordinator.Desktop.Core` へ分離した。
- 文房具ボタンの描画を共通化し、既存の机・手・カメラなどのアイコンを再利用した。
- 配置の削除確認と、最適化の時間指定・進捗・停止・結果通知をアプリ画面内へ移した。
- 既存配置の名前変更へ下線式入力を試験導入。文字編集と Windows の IME・クリップボード接続を分離した。
- 文字の縮小率とキャレットの計測が食い違う問題を修正した。
- Rename の本文には作業の説明を置き、キーボード操作は画面下のモーダル専用帯へ移した。
- モーダル中も Ctrl+P で画面を撮影できるようにした。余白クリックでは入力フォーカスを外す。
- モーダル背後の机がマウスホバーに反応する問題を、描画側の判定と既存ホバー状態の解除で修正した。
- 利用者から、ボタン表示、下線入力、キャレット位置、操作説明の帯、背後の机がホバーに反応しないことの実機確認報告を得た。撮影画像も共有された。
- ファイル選択は Windows 側に残す方針に決定。IME の OS 接続も分離を維持する。文房具 UI の独立リポジトリー化は、２アプリで共通 API を検証してから進める案とした。

共通バージョンを `1.0.1` に更新した。配布 EXE は `CircleSpaceCoordinator.Desktop.Windows.exe`。v1.0.0 と名前が違うため、リリースのダウンロード案内で明示する。既存データはバックアップし、新しい ZIP は別フォルダーへ展開する。

リリース前の Release ビルドは警告・エラー 0 件。C# テスト 137 件（Application 44、Core 24、Desktop 44、Infrastructure 12、StationeryUI 13）と配布チェック 7 件が成功し、CLI のバージョン表示 `1.0.1` を確認した。

次回は IME の詳細操作と未確認のモーダル動作を実機確認し、配置の作成・複製時の名前、机番号、席名などへ下線入力を広げる。一覧・表編集などの残作業は [文房具 UI の移行進捗](文房具UI/移行進捗.md) を参照。クロスプラットフォームでのアプリ実行と、全 Windows フォームの置き換えは未完了。

- 独立プロジェクト `CircleSpaceCoordinator.OptimizationEngine` を追加した。

- 停止時も、それまでの最高案を返す。改善が見つかった場合のみ、元案を残して新しい「自動最適化」配置案として追加する。
- 2スペースサークルは同じ占有セル数の相手と、合体サークルはメンバー全体をひとまとまりとして安全にスワップする。
