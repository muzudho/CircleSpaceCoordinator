# ジャンルコード表を比較して知見を交換する

［ジャンル］の［表を読み込み］からパッケージを開くと、ジャンルコード表の比較・交換画面を表示します。通常の［部分読込み］やパッケージ・ライブラリーからも利用できます。複数の表や別の種類の項目が入っている場合は、比較するジャンルコード表を1つ選んで進みます。

## 左右の見方

- 左：現在のイベントプロジェクトの表。
- 右：読み込んだパッケージの表。

ジャンルコードを一意のIDとして文字コード順に並べ、同じコードを左右の同じ行に表示します。大文字・小文字は別のコードです。［一致］［相違］［左のみ］［右のみ］で違いを示し、その側にない行は灰色で表示します。異なる色・網掛け・コメントのセルは赤みのある背景になります。選択行と縦スクロールは左右で連動します。

## 行ごとの操作

| 操作 | 動作 |
| --- | --- |
| ← 左にコピーを挿入 | 右にだけあるコードを左へ追加 |
| 右にコピーを挿入 → | 左にだけあるコードを右へ追加 |
| ← 左を上書き | 同じコードの右の内容を左へコピー |
| 右を上書き → | 同じコードの左の内容を右へコピー |
| 左を削除／右を削除 | 選んだ側からその行を削除 |
| 左のコードをリネーム／右のコードをリネーム | 下の入力欄に新しいコードを入力して改名 |

コピーでは太線色・細線色・網掛け・コメントをまとめて移します。コピー元は残ります。同じコードが既にある側へ挿入することや、既存コードと同じ名前への改名はできません。［元に戻す］［やり直す］で比較中の操作を戻せます。

この画面での改名・削除は対応表だけが対象です。サークルデータのジャンルは変更しません。使用中のコードの対応を削除した場合、通常のジャンル画面ではそのコードが既定の色・網掛けで表示されることがあります。

## 保存

行を操作しただけではイベントやパッケージのファイルを変更しません。保存する前に下部の［変更内容］を入力します。

- ［左をイベントへ反映］：左側の表をイベントへ反映して保存します。イベント側では1回のUndoでその反映を戻せます。
- ［右をパッケージへ保存］：読込み元のパッケージを更新します。
- ［右を別名保存…］：整理した内容を別のパッケージファイルへ保存します。

左と右の保存は独立しています。左を反映しても右は保存されず、右を保存しても左は反映されません。未反映・未保存の側には印を表示し、そのまま閉じる場合は破棄するか確認します。

パッケージ内の別のジャンルコード表、配置案、素材、知見、タイトル・メモ・タグは保持します。表全体の名前・全体コメント・並び順コメントは元の側のものを維持します。並び順の設定は改名・削除に追従し、比較画面の表示順だけを文字コード順に固定します。

保存に失敗した場合は下書きを残します。元パッケージが別の操作で更新されていたら上書きせず、別名で保存するか読み直してください。マル秘の側からコピーした情報は、コピー先もマル秘として扱います。
