# さあ、始めよう！

Circle Space Coordinator を起動し、配置を編集するまでの手順です。

## 使い始める

配布用 ZIP を受け取った場合は、新しい空フォルダーへ全体を展開し、中の `CircleSpaceCoordinator.Desktop.exe` を起動してください。動作に必要な DLL があるため、EXE だけを取り出さないでください。

ソースコードから起動する場合は Windows と .NET 10 SDK が必要です。[ビルド・起動手順](../../Dev/配布/ソース配布とSmart%20App%20Control.md) を参照してください。

Windows の Smart App Control が有効な環境では、自分でビルドした場合も起動や DLL の読み込みがブロックされることがあります。すべての PC で警告なく実行できることは保証していません。詳しくは [ソース配布と Smart App Control](../../Dev/配布/ソース配布とSmart%20App%20Control.md) にまとめています。

## 基本の流れ

1. 起動時のイベントプロジェクト選択画面で、プロジェクトを新規作成するか、既存の JSON を登録して開きます。
2. 机配置モードで机や席名を整え、サークル配置モードで参加サークルを割り当てます。
3. 配置案を複製して比較し、`Ctrl + S` で保存します。

ドラッグ操作、参加者一覧の取り込み、Excel への書き出し、ショートカットは [アプリの操作説明](../../../CircleSpaceCoordinator.Desktop/README.md) を参照してください。

ZIP 版を更新する場合の設定の引き継ぎは [利用 PC でツールを更新する](../../Dev/配布/リリース手順.md) を参照してください。
