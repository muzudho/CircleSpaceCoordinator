# 自動保存とセーブポイント

2026-09-19更新。**v1.10.0のこの変更から、イベントプロジェクトはオートセーブになりました。従来の［保存］操作は不要です。待たずに保存したいときだけ、［プロジェクト］→［すぐ保存］またはCtrl+Sを使います。** パッケージやExcel・CSVの書出しは手動です。

## 普段の編集

配置の移動、入力の確定、コメントの保存、取込み、Undo/Redoなど、確定した変更が約1.5秒落ち着いたところで保存します。文字の入力途中や、未確定のダイアログ内容は保存しません。画面下に［変更あり・自動保存待ち］→［保存中…］→［保存できています］を表示します。

プロジェクトを閉じるときやアプリを通常終了するときも、確定済みの未保存分を保存します。保存できなければ閉じずにエラーを表示します。［保存せず閉じる］はありません。編集を戻すにはUndo、以前の状態へ戻すにはセーブポイントを使います。強制終了や電源断では、直前の保存待ちの変更は失われることがあります。

保存失敗時は自動再試行を停止します。画面下のエラー表示にマウスを合わせるか、［プロジェクト］の［すぐ保存］に合わせると理由を確認できます。空き容量・アクセス権・バックアップ保存先などを確認して［すぐ保存］で再試行してください。別のアプリがイベントファイルを書き換えた場合は、その変更を上書きしません。現在の編集は手動セーブポイントに退避できます。

## セーブポイント

［プロジェクト］→［セーブポイント…］に、作成・一覧・復元・保護と設定をまとめています。

- **自動作成**：プロジェクトごとに、その日最初の上書き保存の直前に、保存前のファイルを退避します。開いて眺めるだけなら作りません。同じ日に何度開いても原則１回です。
- **手動作成**：［現在の状態を作成］で名前を付けます。確定済みの編集内容を保存します。
- **世代管理**：保護していないものを新しい順に10件保持します。新しいバックアップの暗号化・検証・保存に成功した後、古い通常分を削除します。保持数は1～1000件で変更できます。
- **保護**：一覧の項目を選び、［自動削除から保護］を選ぶと世代整理の対象から外れます。「通常10件＋保護3件」なら合計13件です。保護解除後は、次の作成時から通常の世代整理の対象になります。
- **復元**：一覧から［この状態に戻す］を選び、確認します。復元直前の編集内容も保護付きで退避します。復元後はイベントを開き直すためUndo履歴は終了します。復元の取消しは「復元直前」のセーブポイントから行えます。

通常の自動保存を行う前のバックアップに失敗した場合、イベントファイルを上書きしません。セーブポイントの破損や復号失敗もエラーとして表示します。

## 保存先と暗号化

初期保存先は `%LOCALAPPDATA%\CircleSpaceCoordinator\SavePoints` です。［セーブポイント…］からフォルダーを変更できます。設定はアプリ共通で、バックアップはイベントファイルの絶対パスごとに分けます。同じイベントを移動・改名した場合は別の保存先グループになります。

フォルダーを変更しても古いバックアップを自動移動・削除しません。元のフォルダーへ設定を戻すと、元のバックアップを一覧に表示できます。

**マル秘・通常とも、バックアップの本文と名前はWindowsのDPAPIで暗号化します。** 平文のバックアップや一時ファイルは作りません。復号は原則として作成時と同じPC・Windowsユーザーで行います。別ユーザー、OS再インストールなどで鍵が失われると復号できません。別PCへの受渡し用ファイルではありません。

通常のイベントプロジェクトJSON自体は従来どおり平文です。バックアップを復元しても、現在のイベントのマル秘指定を解除しないようにします。保護付きバックアップは自動で減らないため、必要に応じて保護を解除してください。
