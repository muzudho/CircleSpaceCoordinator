# ［ウィンドウを開いて］から～［配置の決定稿を作る］まで

イベントプロジェクト選択画面が開いたところから、会場と参加サークルを配置し、採用する案を保存するまでを説明します。まだ起動できていない場合は [入手・起動の手順](Installation.md) を先に進めてください。

ここでいう「決定稿」は、内容を確認して採用すると決めた配置案です。本書では案の名前と保存したファイルで管理します。

## 1. イベントプロジェクトを開く

起動時の選択画面で、新しく始める場合はプロジェクトを新規作成します。既存のイベント JSON がある場合は［既存ファイルを登録］から登録して開きます。

作業を保存するイベント JSON の場所を確認してください。アプリのソースフォルダーとは別に保存しておくと、アプリを更新するときにも引き継ぎやすくなります。

## 2. 会場と机・席を整える

［机配置］モードで、会場の大きさを設定し、机を追加・移動・回転して並べます。机番号と、各席のブロック名・席名も設定します。

- ［席名を変更］を選び、机上のセルをクリックして入力します。
- 同じブロック名と席名の組が重複して赤く表示されている場合は、席名を見直します。
- 通路や柱の位置、机の向き、参加サークルに必要な席数が確保できるかを確認します。

ホイールで拡大・縮小、中ボタンのドラッグで画面を移動できます。会場を見失った場合は［会場全体を画面内に収める］ボタンを使ってください。

## 3. 参加サークルの一覧を取り込む

［サークル配置］モードの取込みボタンから、参加サークルの一覧（`.xlsx`、`.xlsm`、`.csv`）を開きます。Excel ファイルではシートを選び、サークル ID・サークル名・必要セル数・合体先サークル ID などの列を対応付けて、プレビューを確認します。

必要セル数と合体の指定は配置に影響します。取り込み後に件数や内容を確認してから、配置作業へ進んでください。既存の一覧を取り込み直すと、削除されたサークルや必要セル数の変更により割り当てが解除される場合があります。

## 4. サークルを席へ配置する

サークルの駒を机のセルへドラッグして割り当てます。配置済みの駒も移動でき、条件が合う駒同士は交換できます。操作を戻すには `Ctrl + Z`、やり直すには `Ctrl + Y` を使います。

一時的に通路などへ仮置きすることもできますが、仮置きが残ったままでは Excel へ書き出せません。最終確認までに机へ戻してください。

作業の途中でも `Ctrl + S` でイベント JSON を保存します。

## 5. 配置案を比較して採用する案を選ぶ

大きな変更を試す前に配置案を複製すると、変更前の案と比較できます。右側の配置案一覧から表示する案を選び、実際の配置と評価を確認します。

評価値だけで決定せず、通路、運営上の条件、必要席数、合体サークルなども確認して、採用する案を選びます。比較用の案を残す場合は、名前を変更して区別してください。

## 6. 決定稿として確認・保存する

採用する案を選択し、次の項目を確認します。

- 配置する予定のサークルが未配置・仮置きのまま残っていない。
- 全ての机に机番号があり、必要な席のブロック名・席名に不足や重複がない。
- 必要席数・合体関係・通路など、イベント側の条件を満たしている。
- 採用する机配置とサークル配置の組み合わせになっている。

配置案の名前を、例えば「決定稿 2026-09-06」のように変更し、`Ctrl + S` で保存します。日付は実際の決定日に置き換えてください。

保存後にアプリを終了し、イベント JSON を日付の分かる別名でコピーして保管すると、その時点の決定稿を残せます。このコピーには比較用の案も含まれるため、採用した配置案名も記録してください。保存した JSON を開き直し、採用案が残っていることを確認します。

## 7. 必要に応じて Excel へ書き出す

決定稿の案を選び、サークル配置モードの書き出しボタンから出力先の Excel ブックを選びます。元のブックを保管し、作業用のコピーを用意して使ってください。シートと、ブロック番号・席番号・サークル ID の列を対応付けます。

仮置きが残っている場合や机番号が未設定の場合は書き出しが止まります。また、席名のない割り当てや未配置のサークルは出力されないため、エラーなく書き出せたことだけで完成と判断しないでください。

出力した Excel を開き、サークル ID と席の対応、対象件数、書き込み漏れを確認してから提出します。最終的なイベント JSON、採用案名、提出用 Excel を一緒に管理してください。

詳しいドラッグ操作やショートカットは [アプリの操作説明](../../../CircleSpaceCoordinator.Desktop/README.md) を参照してください。本書は既存の操作資料と実装に基づく案内で、一連の操作を実機で通して検証したものではありません。
