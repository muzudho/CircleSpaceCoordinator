# ［ウィンドウを開いて］から～［配置の決定稿を作る］まで

イベントプロジェクト選択画面が開いたところから、会場と参加サークルを配置し、採用する案を保存するまでを説明します。アプリは [最新リリース](https://github.com/muzudho/CircleSpaceCoordinator/releases/latest) の ZIP を展開して起動してください。起動できない場合は [ZIP 版が起動しないとき](Installation.md) を参照してください。

ここでいう「決定稿」は、内容を確認して採用すると決めた配置案です。本書では案の名前と保存したファイルで管理します。

## 1. イベントプロジェクトを開く

起動時の選択画面で、新しく始める場合はプロジェクトを新規作成します。既存のイベント JSON がある場合は［既存ファイルを登録］から登録して開きます。

作業を保存するイベント JSON の場所を確認してください。アプリのソースフォルダーとは別に保存しておくと、アプリを更新するときにも引き継ぎやすくなります。

## 2. 会場とフレーム・席を整える

開発版では［机配置］を［フレーム配置］へ改称しています。左上の［次に配置］をクリックすると、［フレーム定義］に登録した型のカタログが開きます。型を選び、［左回転］［右回転］（Q / E）で向きを調整して［決定］（Enter）を押してください。Esc または［キャンセル］で元の選択を保ちます。カタログ表示中も Ctrl+P で撮影できます。

［次に配置］の［向き］ボタンからは、リングの［上向き］［右向き］［下向き］［左向き］で方向を直接選べます。選ぶとリングが閉じ、プレビューと追加時のゴーストへ反映されます。［キャンセル］または Esc では元の向きを保ちます。配置済みのフレームや使用中の道具は変更しません。

［フレーム］リングの［フレーム追加］を選ぶと、会場上に選んだ形のゴーストが現れ、クリックで同じ型を繰り返し配置できます。配置できない場所ではゴーストが赤くなります。カタログで型を選ぶだけでは、使用中の道具は変わりません。配置済みの形は保存され、後から共通定義を編集しても変わりません。

現在、区画の色や壁・入口は表示と形の配置に対応しています。申込スペースによる割当条件や、区画単位でのサークル配置は今後の対応です。

ツールバーの上段では作業モードを選びます。下段は、左側に［ハンド］や机の追加・削除など「選択して使う道具」、区切り線の右側に Undo・保存など「押すたびに一度実行する操作」をまとめています。道具は同時に一つだけ選択できます。［評価分析］の表示切替は道具とは独立したグループです。回転の道具は左側にあり、机を追加中だけは、押すたびに追加予定の机の向きを変えます。

フレーム配置・配置案は右側のリストをクリックして選択します。ツールバーの［前／次の配置］ボタンは廃止しました。項目が多いときは、リスト右端のスクロールバーのつまみをドラッグするか、つまみの上・下の余白をクリックしてページ単位で移動できます。リスト上でのホイール操作も使えます。

［フレーム配置］モードで、会場の大きさを設定し、フレームを追加・移動・回転して並べます。番号は［ブロック番号］［フレーム番号］［セル番号］のチャンネルを選び、［番号入力］で入力します。画面には選択中の番号だけを表示します。

ブロック番号・セル番号は席のセル単位、フレーム番号はフレーム全体で共通の値です。ブロック番号とセル番号は別々に入力・削除でき、片方を変更しても他方は保たれます。空欄で確定すると選択中の番号だけを削除します。席ではないセルは番号入力の対象外です。セル単位の番号は範囲選択による一括入力にも対応します。重みチャンネルを選んだ場合は、同じボタンで重みを入力します。

- チャンネルを選び、［番号入力］で席のセルをクリックして入力します。
- 同じブロック名と席名の組が重複して赤く表示されている場合は、席名を見直します。
- 通路や柱の位置、机の向き、参加サークルに必要な席数が確保できるかを確認します。

ホイールで拡大・縮小、中ボタンのドラッグで画面を移動できます。会場を見失った場合は［会場全体を画面内に収める］ボタンを使ってください。

未入力の番号は薄い赤の塗りと `？` で表示します。ブロック番号・セル番号では対象セルごとに、フレーム番号ではフレーム全体に1つ表示します。席ではないセルにはブロック番号・セル番号の未入力表示を出しません。番号を入力すると通常の番号表示に戻ります。

## 3. 参加サークルの一覧を取り込む

初めて試す場合は、架空のデータを入れた [きふわらべオンリー即売会_参加サークル一覧.xlsx](../../../examples/きふわらべオンリー即売会_参加サークル一覧.xlsx) を使えます。リンク先の GitHub ファイル画面でダウンロードし、保存した Excel ファイルを次の手順で開いてください。

［サークルデータ］モードの［Excel / CSV 読込］から、参加サークルの一覧（`.xlsx`、`.xlsm`、`.csv`）を開きます。Excel ファイルではシートを選び、サークル ID・サークル名・必要セル数・合体先サークル ID などの列を対応付けて、プレビューを確認します。

CSV の文字化けや文字コードのエラーが出た場合は、読込み画面上部の［CSV の文字コード］を［Shift-JIS（Windows / CP932）］へ切り替えてください。既定は［UTF-8（BOM あり／なし）］です。読み取れない文字も `�` に置き換えて表に表示するので、切替前後で見比べられます。読み取れない文字を検出した間は案内を表示し、取込みを無効にします。選び直すと元ファイルを読み直し、プレビューと列の候補を更新します。文字化けをすべて検知できるわけではないので、サークル名と列の対応が正しいことを確認してから［この対応で取り込む］を押してください。元の CSV は書き換えません。

Excel から CSV に書き出した時点で欠損した文字は、文字コードを切り替えても復元できません。元の Excel ファイル（`.xlsx`）から読み込み直してください。この注意は CSV の読込み画面にも常に表示されます。

必要セル数と合体の指定は配置に影響します。取り込み後に件数や内容を確認してから、配置作業へ進んでください。既存の一覧を取り込み直すと、削除されたサークルや必要セル数の変更により割り当てが解除される場合があります。

## 4. サークルを席へ配置する

サークルの駒を机のセルへドラッグして割り当てます。配置済みの駒も移動でき、条件が合う駒同士は交換できます。操作を戻すには `Ctrl + Z`、やり直すには `Ctrl + Y` を使います。

一時的に通路などへ仮置きすることもできますが、仮置きが残ったままでは Excel へ書き出せません。最終確認までに机へ戻してください。

作業の途中でも `Ctrl + S` でイベント JSON を保存します。

## 5. 配置案を比較して採用する案を選ぶ

［サークル配置］と［ジャンル配置］では、右側の［配置案］リストの上に親の［机配置］名を表示します。机配置名をクリックすると選択ダイアログが開き、その机配置に属する配置案へ表示を切り替えられます。配置案の紐づけ先そのものを変更したいときは、配置案を選んで［Link］を使ってください。

大きな変更を試す前に配置案を複製すると、変更前の案と比較できます。右側の配置案一覧から表示する案を選び、実際の配置と評価を確認します。

評価値だけで決定せず、通路、運営上の条件、必要席数、合体サークルなども確認して、採用する案を選びます。比較用の案を残す場合は、名前を変更して区別してください。

## 6. 決定稿として確認・保存する

採用する案を選択し、次の項目を確認します。

- 配置する予定のサークルが未配置・仮置きのまま残っていない。
- 全ての机に机番号があり、必要な席のブロック名・席名に不足や重複がない。
- 必要席数・合体関係・通路など、イベント側の条件を満たしている。
- 採用する机配置とサークル配置の組み合わせになっている。

配置案の名前を、例えば「決定稿 2026-09-06」のように変更し、`Ctrl + S` で保存します。日付は実際の決定日に置き換えてください。

名前変更の下線付き入力欄では、マウスドラッグで文字を選択できます。`Ctrl + C` でコピー、`Ctrl + X` で切り取り、`Ctrl + V` で貼り付け、`Ctrl + Z` で元に戻せます。`Shift` を押しながらクリックすると、現在のカーソル位置から選択範囲を広げられます。

保存後にアプリを終了し、イベント JSON を日付の分かる別名でコピーして保管すると、その時点の決定稿を残せます。このコピーには比較用の案も含まれるため、採用した配置案名も記録してください。保存した JSON を開き直し、採用案が残っていることを確認します。

## 7. 必要に応じて Excel へ書き出す

決定稿の案を選び、サークル配置モードの書き出しボタンから出力先の Excel ブックを選びます。元のブックを保管し、作業用のコピーを用意して使ってください。シートと、ブロック番号・席番号・サークル ID の列を対応付けます。

仮置きが残っている場合や机番号が未設定の場合は書き出しが止まります。また、席名のない割り当てや未配置のサークルは出力されないため、エラーなく書き出せたことだけで完成と判断しないでください。

出力した Excel を開き、サークル ID と席の対応、対象件数、書き込み漏れを確認してから提出します。最終的なイベント JSON、採用案名、提出用 Excel を一緒に管理してください。

詳しいドラッグ操作やショートカットは [アプリの操作説明](../../../CircleSpaceCoordinator.Desktop.Windows/README.md) を参照してください。本書は既存の操作資料と実装に基づく案内で、一連の操作を実機で通して検証したものではありません。
