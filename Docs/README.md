# 文書の目次

アプリのタイトルバーで使用中のバージョンを確認し、目的に合う入口を選んでください。

- [利用者向け](User/README.md)：インストール、操作、困ったときの手順
- [開発者向け](Dev/README.md)：ビルド、設計、配布、調査記録

版別の説明は各入口の `Version/` にあります。現在の作業ツリーの `Directory.Build.props` は v1.13.0 ですが、公開タグ v1.13.0 より後の変更を含みます。公開した版の仕様は、その版の Git タグで文書とコードを確認してください。作業ツリーの文書を公開タグの説明として使わないでください。

作業の再開時は[続きはここから](続きはここから.md)を先に読んでください。個人用メモは版別の公式案内に含めません。

## 文書を更新するとき

現行版の本文は利用者・開発者それぞれの `Version/<版>/` に一つだけ置きます。次の版へ進むときは現行文書を新しい版のフォルダーへ移し、目次とリンクを更新してください。過去の公開版は Git タグの文書を正本とし、同じ説明を新しいフォルダーへコピーして増やしません。日付で追う開発日誌と廃止記録は、版別の操作手順とは分けて保管します。
