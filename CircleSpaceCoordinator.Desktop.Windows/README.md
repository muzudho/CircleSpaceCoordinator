# Desktop executable

［ジャンル配置］のツールバーにある魔法の杖は、未配置・仮置きのサークル石を空いている配置可能セルへ一括配置します。シンキングエンジンで合体グループと必要セル数を確認し、配置済みの石を動かさず、同じフレームに収まる空きを探します。配置未確定セルには置きません。収まらない石は元の状態で残し、完了時に配置数と残数を表示します。現在のサークル配置案を更新し、１回の Undo／Redo で戻せます。評価値の最適化や全員が収まる組合せの完全探索は行いません。

上段の［フレーム配置］［島定義］と［ジャンル配置］［サークル配置］は、それぞれ先頭ボタンの左上にある角丸の［－］でまとめて収納できます。収納後は後続のボタンが左へ詰まり、［＋］を押すと再表示します。現在のページは切り替わりません。収納状態はアプリ起動中に保持し、再起動すると両グループを展開します。

［フレーム定義エディター］の辺設定はプレビューの上下左右に対応させて配置します。幅・高さを変えると設定ボタンも外周に追従します。外周には壁をオレンジの太線、入口を中央が開いた緑の線、正面を水色の線で表示し、開放には線を追加しません。設定を切り替えるとプレビューへ即時反映します。

［スペース番号書き出し］ページの上部には、書き出し対象のサークル配置案の名前と小さな配置図プレビューを表示します。隣の［変更］で書き出す配置案を選び直せます。作業中の案とは別に、保存済みの書き出し対象を表示し、未決定の場合はその旨を示します。

サークル配置案を作成すると、未配置サークルの石をフレーム・柱・仮置き済みの石を避けて通路へ並べます。通路に入りきらない石は、会場の下に1行空けて左から並べます。必要スペース数を保ち、配置が進んで空きができると、残りの未配置の石を前へ詰めます。これは未配置サークルの表示位置であり、手動で仮置きした石の保存位置は維持します。ドラッグでフレームへ配置したり、通路や会場外へ手動で仮置きできます。

操作部品の［選択］は緑色の背景、［操作の対象］は水色の枠線で別々に示します。通常のボタン・カタログカードには装飾用の枠線を付けません。共通ボタンは `OperationButtonRenderer` で描画し、水色の枠はマウスが乗っている部品とキーボードの操作対象にだけ表示します。選択されている部品が操作対象でもある場合は、緑背景と水色枠を併用します。

［フレーム定義エディター］では、セルを1回クリックするたびに［配置可能セル］と［配置未確定セル］を切り替えます。配置可能セルにはサークル配置ページと同じオレンジ色の丸を表示し、配置未確定セルには印を付けません。矢印キーで移動してSpace/Enterでも切り替えられます。フレーム内の区画分けと数字の選択はありません。セル間の接続は［接続を編集］で設定します。

［申込スペースエディター］の割当先は、3列×2段のプレビューカタログからフレーム単位で選びます。配置可能セル数・選択状態をカードに、長い型名と拡大プレビューを右側に表示します。クリックで複数選択・解除、矢印キーで移動、Space/Enterで切替、ホイール・PageUp/Down・前後ボタンでページを切り替えます。［保存］で確定し、［キャンセル］では編集を破棄します。

［フレーム配置］の［フレーム番号］チャンネルでは、チャンネルリスト下の魔法の杖から旗順の自動連番を開けます。開始番号を入力し、変更前後を確認して適用します。旗から入口方向へたどったシーケンスで、初めて現れるフレームに1番号ずつ付けます。選択があれば選択フレーム、なければ旗から到達する全フレームが対象です。複数の旗は会場の上→左の順に処理し、番号を続けます。対象外のフレーム番号、ブロック番号、セル番号は保持し、1回のUndoで戻せます。

［セル番号入力ウィザード］の並び順にも［旗からの順番］があります。セル番号のリスト入力とフレームごとの繰り返しを利用できます。対象経路に分岐があるツリーはダイアログで理由を表示し、自動連番しません。輪でも入口から出口までがシーケンスなら利用できます。旗がない場合や選択対象に旗から到達できないセルがある場合も、変更前に止めます。セル番号では選択範囲（未選択なら全配置可能セル）に到達できるよう旗と入口方向を設定してください。

左端の［サークルデータ］では、取り込んだ値を表で確認できます。［Excel / CSV 読込］をここへ集約し、ジャンル配置・サークル配置から読込ボタンを移しました。縦横スクロールバー、ホイール（Shift で横）、矢印、PageUp/Down、Home/End に対応し、セルをクリックすると全文を確認・コピーできます。書式は再現せず、数値はアプリが取り込んだ実数値を表示します。取込み元の名前・シート・列順は JSON 保存と Undo/Redo に対応します。旧データは保存済みの列値、なければ基本情報を表示します。

初期表示は［配置案　未決定］です。［配置決定案を選択する］で書出し用の案を決定し、［書き出す］でその案の席番地を Excel に反映します。未決定の間は書き出せません。作業中の案を切り替えても決定案は変わらず、JSON 保存・Undo/Redo に対応します。決定案を削除すると未決定に戻ります。選択画面で未決定へ戻すこともできます。書出し操作は［サークルデータ］に集約し、［サークル配置］の書出しボタンは撤去しました。案の内容を凍結する機能ではなく、書出し時点の内容を使います。表は閲覧専用です。[設計と性能方針](../Docs/Dev/設計/サークルデータモード.md)

## チャンネルとセルの重み

［机配置］モードの右側に、［机配置］リストと、その下の［チャンネル］リストを表示します。どちらのリストも、マウスを重ねてホイールでスクロールできます。

- ［番地］はブロック名・机番地・セル番地を編集する特別なチャンネルです。削除や Excel 列の対応付け、採点は行いません。
- ［追加］でチャンネルを作成し、［列・名前］で名前と、取り込んだ Excel / CSV の列を設定します。例えば［書籍］を作り、［書籍の有無］列を対応させます。先に［サークル配置］または［ジャンル配置］モードの取込みボタンから一覧を読み込んでください。既に読み込んだ古いプロジェクトで列が表示されない場合は、元の表を再度取り込んでください。
- 数値チャンネルを選び、机上のセルをクリックして 0～1 の重みを入力します。Ctrl＋ドラッグで範囲を選び、範囲内の机上セルをクリックすると一括入力できます。セルの色と数値で重みを確認できます。別の机操作ツールを選んだ後は、チャンネルを選び直すと重み入力へ戻ります。
- 新規チャンネルの未入力セルは 0 です。重みは会場の座標に保存し、机配置間で共有します。机を動かしても明るさなどの場所の条件は元の位置に残ります。
- チャンネルの部分点は、配置済みサークルについて「対応列の値 × 採点位置のセルの重み」を合計した値です。複数セルのサークルも既存の採点位置で 1 回だけ加点し、未配置・仮置きは加点しません。新規チャンネルは倍率 1、加算値 0 で、番地以外の全チャンネルの部分点を合計します。既存プロジェクトの評価項目に設定済みの倍率・加算値は互換性のため維持します。
- 対応列の空欄は 0 とし、数値でない値や無限大などは対応付け・再取込み時にエラーにします。対応先の列が再取込みした表にない場合も、変更を適用しません。

チャンネルの定義、列の対応、セルの重みと取込み元の列データはプロジェクト JSON に保存します。Excel 側を編集した場合は再取込みで更新します。チャンネル追加・編集・削除、重み入力、取込みは Undo/Redo に対応します。リストには選択中のサークル配置の部分点と合計を表示します。サークル配置がない机配置は 0 点です。既存の合体違反時の評価ルールは引き続き適用します。

## 既存機能

［サークル配置］モードでは、右側の配置リストの下の［チャンネル］から石の表示内容を切り替えます。［サークル名］［サークルID］［内部ID］（従来の石番号）と、作成済みの数値チャンネルを選べます。例えば［書籍］を選ぶと、対応列から取り込んだそのサークルの値（0、1 など）を表示します。配置済み・未配置・仮置き・ドラッグ中の石に同じ表示設定を使います。リストはホイールでスクロールできます。

従来のツールバーの［ID］ボタンは、このリストへ移しました。リスト上部の［サークルIDの正規表現］で正規表現と置換文字列を設定できます。設定はサークルID表示だけに適用し、サークル名や数値チャンネルには適用しません。表示を切り替えても正規表現は保持されます。表示の選択と正規表現はアプリの設定に保存し、再起動時に復元します。選択したチャンネルが削除された場合や、別のプロジェクトに存在しない場合は内部ID表示に戻ります。

エディター GUI は、起動時に `engines/editor/` と `engines/thinking/` のヘッドレスエンジンを非表示で起動し、gRPC で接続します。編集状態と履歴はエディターエンジンが管理します。通常のビルドと publish で２つのエンジンも同梱されるため、実行ファイルだけでなくフォルダー全体を使用してください。[構成・API・復旧手順](../Docs/Dev/設計/ヘッドレスエンジンとgRPC.md) を参照してください。

Windows 用の実行・画面処理を担当します。ドラッグや編集コマンド、設定・プロジェクト保存などの共通処理は [Desktop.Core](../CircleSpaceCoordinator.Desktop.Core/README.md) にあります。

ジャンル配置・サークル配置では、スペースを通路や会場グリッドの外へドラッグすると、その場所へ仮置きできます。机へドラッグすれば正式な配置に戻り、同じスペース数の駒同士は仮置きとの交換もできます。複数の駒は `Shift` で範囲選択してから範囲をドラッグすると、通路も含めて交換できます。机と通路にまたがる配置や、柱・他の仮置きと重なる配置は受け付けません。

仮置き位置は配置案ごとに保存され、複製とアンドゥ／リドゥにも対応します。画面外にある未配置スペースは、画面端の矢印と件数で方向を表示します。下部にも仮置き件数を表示し、仮置きが残った状態ではExcelへ書き出せません。

ゲーム画面がアクティブなとき、`Ctrl + P`またはツールバー右端のカメラボタンでPNGスクリーンショットを保存できます。保存先はピクチャーフォルダー内の`CircleSpaceCoordinator/Screenshots`です。撮影成功後はシャッター音と視覚エフェクトを再生し、エフェクト自体はPNGへ含めません。

視覚エフェクトは `StationeryUI.MonoGame.Effects.ScreenshotEffect`、シャッター音は `StationeryUI.MonoGame.Audio.ScreenshotShutterSound`（同梱の `StationeryUI.MonoGame` 0.1.1）を使用します。共通実装のソースは StationeryUI リポジトリーの `src/StationeryUI.MonoGame/Effects/ScreenshotEffect.cs` と `src/StationeryUI.MonoGame/Audio/ScreenshotShutterSound.cs` です。アプリ側は入力・PNG保存・演出時間（0.42秒）・音量・音声リソースの破棄を担当します。共通実装を更新した際は、新しいバージョンのパッケージを作成し、`LocalPackages/StationeryUI` とパッケージ参照を更新して取り込みます。

ウィンドウは通常のWindows操作でリサイズできます。ツールバーの手のひらアイコンの右隣にある「会場全体を画面内に収める」ボタンを押すと、右側の配置案パネルと上下のUIを避けて、会場全体を表示領域の中央へ収めます。画面を広げた後や、ズーム・パンで会場を見失ったときに使用します。

机配置モードの「席名を変更」ボタンを選び、机上のセルをクリックすると、そのセルのブロック名と席名を入力できます。席名は机にひも付くため、机の移動・回転にも追従し、机を削除すると一緒に削除されます。同ツールでは、`Shift`を押しながらドラッグして複数セルを範囲選択し、選択範囲をもう一度クリックするとブロック名・席名をまとめて上書きできます。ブロック名だけ、または席名だけを先に設定することもできます。既存値が混在する場合は、上書き前に確認します。`ア` と `10左` のような同じブロック名・席名の組が複数セルにある間は、該当する席名札を赤く表示します。席名を整えて組が一意になると通常色へ戻ります。机配置モードの配置案リストにある「色んなコピー」からは、コピー元・コピー先・コピー方法を選んで「机配置だけコピー」を実行できます。この方法では机、席名、島定義をコピーし、コピー先のサークル配置は維持します。維持できないサークル配置がある場合はコピーを中止します。

操作対象は水色の枠、選択中のものは半透明のハイライトで表示します。机配置の「机番号を変更」「机を移動」「机を削除」「机を回転」では、マウス位置の机１台全体に枠を付けます。「席名を変更」は対象セル、選択範囲内ではまとめて編集する範囲に枠を付けます。机のドラッグ中は元の机をハイライトし、移動先に水色の枠を表示します。番号未設定などの赤い警告は引き続き表示します。

机配置・ジャンル配置・サークル配置モードでは、キャンバス上で `Shift` を押しながら左ドラッグすると、選択中のツールや `Space` による画面移動よりも範囲選択を優先します。机配置では「席名を変更」以外のツールでも範囲選択できます。ドラッグ途中で `Shift` を離しても、マウスボタンを離すまでは範囲選択を続けます。

`Ctrl + S`またはツールバーのフロッピーディスクボタンで編集中のJSONを保存します。引数で開いたJSONは同じファイルへ保存します。引数なしで開く内蔵の架空サンプルは上書きせず、ドキュメントフォルダー内の`CircleSpaceCoordinator/Projects/fictional-working-copy.json`へ保存します。

`Ctrl + O`またはツールバーのフォルダーボタンで、標準ファイル選択ダイアログから別のJSONプロジェクトを開きます。読込み後の保存先は、選択したJSONへ切り替わります。

実行ファイルと同じフォルダーの`application-settings.json`へ、プロジェクト保存フォルダーと最後に開いたプロジェクトを記録します。次回起動時は最後のプロジェクトを自動的に開き、ファイルが見つからない場合は架空サンプルへ戻ります。コマンドラインでJSONを指定した場合は、その指定を優先します。

配置案一覧の日本語と評価値は、WindowsにインストールされたMeiryoを実行時にラスタライズし、再利用可能なMonoGameテクスチャとして描画します。

右側の配置案パネルにある`Duplicate`ボタンで、選択中の配置案を複製できます。座標を持つサークルは番号付きの駒として表示し、配置未確定セル上でもその位置を保持します。座標のないサークルは自動整列せず、割当て操作で配置します。合体サークルの2駒は連結表示します。

画面右側には配置案を評価値の高い順で並べた一覧を表示します。行のバーが相対的な評価値、明るい緑が現在案です。行をクリックすると案を切り替えられます。前／次ボタンと`Tab`も評価順に移動します。ツールバーの重なった用紙＋印のボタンは現在案を「配置修正」版として複製し、新しい案を選択します。

GUI実行ファイルのプロジェクトです。`CircleSpaceCoordinator.Desktop.Windows.csproj` は、画面用の `Application`、JSON入出力の `Infrastructure`、GUI部品の `StationeryUI` を参照します。

グリッド、机のドラッグ＆ドロップ、参加者割り当て、ヒートマップ、配置案比較を担当します。評価計算そのものは `Core`、操作の調停は `Application` を利用します。

`DesktopApplication.LoadWorkspace` でJSONプロジェクトを画面用の `ProjectWorkspace` として開けます。

`VenueEditorGame` はMonoGame DesktopGLのウィンドウを開き、会場グリッド、机、ドラッグプレビューを描画します。中ボタンドラッグでパン、ホイールでズーム、左ドラッグで机を移動できます。

ツールバー先頭の机アイコンと石アイコンで、［机配置モード］と［サークル配置モード］を切り替えます。机配置モードでは会場サイズと机を編集し、サークル石を隠します。サークル配置モードでは机編集ボタンを隠し、参加サークルの石、一覧取込み、割当て、解除に必要なボタンを表示します。

両モード共通のハンドツールを選択すると、マウス左ドラッグで会場グリッド、机、石をまとめて画面内で移動できます。この操作は表示位置だけを変え、JSON内の配置座標やUndo履歴は変更しません。従来どおりマウス中ボタンドラッグでも移動できます。

現在の表示倍率と表示位置は、保存時にイベントプロジェクトへ1組だけ記録されます。配置案を切り替えても表示は変わらず、次に同じプロジェクトを開いたときにも復元されます。古いプロジェクトJSONに表示状態がない場合は、従来の初期倍率・初期位置で開きます。

サークル配置モードの取込みボタンから `.xlsx`、`.xlsm`、`.csv` を開けます。ExcelはClosedXMLで直接読み込むため、PythonおよびMicrosoft Excelは不要です。Excelではシートを選び、サークルID、サークル名、任意の必要セル数、任意の合体先サークルIDの列を対応付け、先頭100行のプレビューを確認してから取り込みます。同じサークルIDは内部IDを維持し、一覧から消えたサークルや必要セル数が変わって不整合になった割当ては解除されます。

取込みを試す場合は、架空の [きふわらべオンリー即売会_参加サークル一覧.xlsx](../examples/きふわらべオンリー即売会_参加サークル一覧.xlsx) をダウンロードして使えます。

サークル配置モードの書き出しボタンから、既存の `.xlsx` または `.xlsm` を選び、シート、ブロック番号列、席番号列、サークルID列を指定できます。選択中の配置案でサークルIDの採点位置に設定された席名を、同じサークルIDのExcel行へ書き込みます。席名未設定・未配置のサークルや、Excel内に見つからないサークルIDの行は変更しません。

サークル石をクリックするとそのサークルを選択し、割当てツールへ切り替わります。石に表示する `1..n` は人向けの石番号で、アプリの内部ID、イベントから渡される任意文字列のサークルID、サークル名とは別に扱います。

サークル配置モードでは、未配置または配置済みの石をマウス左ボタンでドラッグできます。ドラッグ中は青白い石のゴーストがカーソルへ追従し、机のセル上で離すと割当てまたは再割当てを1回のUndo対象操作として確定します。配置済みの石を机のない場所で離すと割当てを解除します。机の上だが容量不足や重複で割当てできない場合は元の配置を維持します。未配置の石とドラッグゴーストは必要セル数分の大きさで描き、合体先サークルIDで組になった石は隣接させて連結表示します。

配置済みの石を机上の別の石へドロップすると、2つのサークル配置を1回のUndo対象操作としてスワップします。必要セル数や合体サークル制約が交換先と合わない場合は交換を拒否し、両方の配置を維持します。

引数なしでは、本体ウィンドウの最初のページに文房具UIの［イベントリスト］を表示します。別ウィンドウの Windows Forms 選択画面は使用しません。ここから新規作成、既存JSONの登録、複製、マル秘設定、一覧の上下移動、一覧からの除外ができます。名前・JSONファイルのパス・確認メッセージも本体内で入力・表示します。パスは貼り付け可能です。一覧から除外してもJSONファイル自体は削除されません。第1引数へJSONパスを渡した場合は、そのプロジェクトを同じウィンドウで開きます。開けない場合は一覧上にエラーを表示します。

一覧はクリックまたは↑↓で選択、［開く］または Enter で開きます。Tab / Shift+Tab で一覧と操作ボタンを移動し、ホイール・PageUp / PageDown で長い一覧を移動できます。編集画面のフォルダーと左矢印のボタン［イベントリストに戻る］、Ctrl+O、またはモーダルを開いていない状態の Esc で、［保存して戻る］［保存せず戻る］［キャンセル］を確認します。初期選択はキャンセルです。保存失敗時はエラーを表示し、イベントを開いたままにします。戻る際はエンジンの編集セッションを閉じ、選択・Undo履歴を次のイベントへ持ち越しません。フレーム定義モードからも戻るボタンを使用できます。

一覧の実装は `VenueEditorGame.Events.cs`、保存と閉じる判断は OS 非依存の `ProjectCloseWorkflow` にあります。`StationeryUI` のボタン・モーダル・テキスト編集を使い、イベント固有の処理はアプリ側に置いています。日本語IME・文字描画の Windows 接続、および他の既存編集ダイアログは引き続き Windows 実装です。

［ジャンル配置］の［ジャンルと色・網掛けパターンの対応］は、本体内の文房具UIで編集します。主色・副色のセルは設定色を背景に表示し、1回クリックすると15色の見本と任意の `#RRGGBB` 入力を選べます。網掛けセルは8種類の実描画見本を並べたポップアップを開きます。白黒見本は黒＝主色、白＝副色で、会場と同じパターン描画を不透明な2色で使用します。右端には主色・副色を使った配色見本も表示します。単色の副色セルは無効になり、値は保持されるため網掛けへ戻すと再利用できます。

矢印キーでセル移動、Enter / Spaceで選択画面を開きます。選択画面はクリック、Tab・矢印＋Enterで操作でき、Escで変更せず戻れます。ホイール・PageUp / PageDown・前後ボタンでジャンル一覧をスクロールします。設定画面の［保存］またはCtrl+Sはイベント内へ1回のUndo対象操作として反映し、キャンセルは下書きを破棄します。JSONファイルへの保存は編集画面のCtrl+Sで行います。色コード不正やエンジンエラー時は本体内にエラーを表示し、下書きを保持します。現在の参加者に含まれないジャンルの既存設定も保持します。

色・網掛けの共通UIは `VenueEditorGame.StyleMappings.cs`、OS非依存の下書きは `StyleMappingDraft` にあります。`StyleMappingEntry` はジャンル専用ではない文字列キーと主色・副色・パターンを持ちます。`OpenStyleMappingEditor(draft, keyLabel, emptyMessage, apply)` に下書き・対象名・空一覧の説明・保存処理を渡すと、ブロック番号などにも同じUIを利用できます。保存処理が失敗した場合は下書きを保持します。ジャンルの一覧取得と既存モデルへの変換は `GenreStyleDraft`、エンジンへの反映は `VenueEditorGame.GenreStyles.cs` が担当します。［フレーム配置］で［ブロック番号］チャンネルを選ぶと、チャンネルリストの下に［色・網掛けの対応］ボタンを表示します。イベント内の全フレーム配置から重複を除いたブロック番号を編集し、設定はイベント共通の `BlockStyles` として保存します。保存は1回のUndo対象操作で、未使用の設定も保持します。番号がない場合は入力を促す案内を表示します。［ブロック番号］ではShift＋ドラッグでセル単位の範囲を選択し、Shiftを離して範囲内をクリックすると番号を一括入力できます。対象は配置可能セルのみで、フレームの一部も選択できます。背景には共通設定の主色・副色・網掛けを描き、フレームは枠線と向きの印で表示します。番号の文字は会場座標の4×4セル区画ごと・ブロックごとに1か所、そのブロックに属するセル上へ表示します。小さなブロックにも文字を表示し、未入力セルは従来の「？」表示を保ちます。

［フレーム定義］の追加・編集・複製は、本体内の文房具UIエディターで行います。型の名前を押すと日本語入力欄が開き、種類と四辺の属性はボタンを押すたびに切り替わります。幅・高さは1～12セル。パレットで［消す］［席なし］［1～9］を選び、グリッドをクリック・ドラッグして塗ります。右クリックで消去できます。Tab / Shift+Tabで部品を移動し、グリッドにフォーカスがあるときは矢印でセル移動、Space / Enterで塗り、Delete / Backspaceで消去できます。申込スペースの読込み値・説明と、複数の型・区画への割当先も同じウィンドウ内で編集できます。割当先はクリックまたはSpaceで選択し、ホイール・PageUp / PageDown・前後ボタンでスクロールします。

［保存］またはCtrl+Sで共通定義を検証して保存し、［キャンセル］またはEscで下書きを破棄します。入力・検証・保存エラーの表示も本体内です。保存失敗時は下書きを残します。寸法を縮小しても編集中は隠れたセルを保持し、保存時に範囲外のセルを取り除きます。代表セル不足や申込スペースが参照する区画の削除、他プロセスによる定義の更新は従来どおり保存を拒否します。編集中もCtrl+Pで撮影できます。UIは `VenueEditorGame.FrameEditor.cs`、OS非依存の下書きは `SpaceDefinitionDraft` に分離しています。旧 `SpaceDefinitionDialog` のWindows Forms実装は削除しました。

JSON読込み時は配置禁止セル、机、割当てセル、サークルIDの採点位置を色分けします。`Tab` / `Shift+Tab` で案を切替え、マウス位置の机を `E` / `Q` で右・左回転し、`Ctrl+Z` / `Ctrl+Y` でUndo/Redoできます。

エディターのタイトルバーにはアプリケーション名とイベント名を表示します。画面下部のステータスバー上段には、マウスを合わせたボタンの操作説明を即時表示します。下段のタイマー付き操作説明と保存・スクリーンショットなどの結果表示は維持します。フレーム配置では、配置可能スペース数・要求スペース数・一致／不足／超過の判定を左側の［次に配置］の下に表示します。

未割当てサークルは `↑` / `↓` で選択し、マウス位置の机へ `A` で割り当てます。マウス位置の割当ては `Delete` で解除できます。選択中のサークル名はウィンドウタイトルへ表示し、ログには名前やIDを出しません。

画面上部のアイコンツールバーから、前後の配置案、Undo、Redo、机の左・右回転、サークル割当て、割当て解除をクリック操作できます。ホバー中はウィンドウタイトルへ日本語の操作名を表示し、無効な操作は暗色表示にします。

机追加ツールを選んで会場セルをクリックすると、標準の2セル机を追加します。追加前はマウス位置に青白いワイヤーフレームのゴーストを表示し、実際に占有するセルと向きを確認できます。机追加モードのままツールバーの左回転・右回転ボタンを押すと、モードを解除せずにゴーストを90度回転できます（キーボードの `Q` / `E` でも同じ操作ができます）。配置禁止セル、会場外、既存机との重なりによって配置できない位置ではゴーストが赤色になります。最後に移動または回転した机の向きを記憶し、次に追加する机へ引き継ぎます。次の向きは画面下部の「次の机」欄に表示し、各机の正面側の辺には机色より少し濃い短い印を表示します。机削除ツールはクリックした机を削除しますが、サークル割当てが残る机は削除を拒否します。自動配置ボタンは配置禁止セルと既存机を避けて空き領域を2セル机で埋めます。［会場サイズ］のリングでは、上下左右それぞれの辺を１セル伸ばす・縮める８操作とキャンセルを選べます。選択するとその場で１回実行し、リングを開いたまま続けて押せます。キャンセルまたはEscで閉じます（実行済みの伸縮は取り消しません）。上・左の伸縮では全配置の机・柱・サークル・島定義・評価用の重みをまとめて平行移動し、位置関係を保ちます。縮小で既存要素が会場外へ出る場合やサイズが１セル未満になる場合は拒否します。Ctrl+Zで元に戻せます。

机の追加・削除は、ツールバーの［机］ボタンから選びます。押すと［机追加］［机削除］［キャンセル］がリング状に開き、選んだツールが元のボタン位置に選択中の表示で置かれます。そのボタンを再度押すと選び直せます。キャンセルまたは Esc では元の選択を保ちます。リング表示中は画面全体を半透明の黒で覆い、背後のマウス操作・キー操作を停止します。Tab・矢印キーでリングのボタンを選び、Enter・Space で決定することもできます。

［机］とリング内のボタンは正方形のアイコンです。円形の帯の上に追加・削除・キャンセルの３つを配置し、中心は空けています。キャンセルは × アイコンです。リング表示中も例外として Ctrl+P によるスクリーンショット撮影を利用できます。

柱も［柱］アイコンから［柱追加］［柱削除］［キャンセル］のリングを開いて操作します。選択したツールのアイコンを元の位置に選択表示し、再クリックで選び直せます。机・柱ともリングのボタン自体には選択中の緑色を付けず、マウスを合わせたボタンの説明を画面下の暗幕より手前に表示します。

［フレーム配置］の［フレーム］リングメニューから［フレーム削除］を選び、フレームをクリックすると確認なしで本体を削除します。番地・補助接続・自動接続の無効化設定も対象フレーム分を取り除きます。フレームを共有する全配置案のサークルは、元の座標・占有セル・合体情報を保持して仮置きになります。削除後は1回のUndoで本体・番地・接続・配置を復元できます。配置可能セルでない場所は［配置未確定セル］と呼び、そこに置いたサークルも位置を保持します。座標のない未配置サークルを左上へ自動整列する表示は廃止し、割当て操作で配置します。

架空サンプルは全サークルが割当て済みなので、最初は割当て（＋）が無効です。解除（×）でサークルを一つ外すと＋が有効になり、＋を選んで机セルをクリックすると再割当てできます。

GUI操作は実行ファイル横の `logs/ui-operations-*.jsonl` へ記録します。時刻、操作名、画面座標、グリッド座標、成功可否、検証コードだけを記録し、サークル名・サークルID・業務値は記録しません。`logs/` はGit対象外です。

`VenueCanvasMapper` がCoreの整数座標とStationeryUIのキャンバスセルを変換し、GUI部品DLLに計算DLLへの依存を持ち込まないようにします。

`Interaction/DeskDragController.cs` は、机のヒットテスト、ドラッグ中のプレビュー、ドロップ時の確定を扱います。ドラッグ中はプロジェクトを変更せず、正常なドロップだけをUndo履歴へ1操作として追加します。

一覧上部の［複製］は、その一覧で選択している項目を複製します。机配置の一覧では机・席名・島の設定を引き継ぐ独立した机配置を追加し、サークル配置案の一覧では同じ机配置に紐づくサークル配置案を追加します。名前を指定して確定すると複製先を選択します。ツールバーには複製ボタンを置きません。

［セル番号］チャンネルでは、リスト下の魔法の杖アイコンから［セル番号入力ウィザード］を開けます。割り当て方式・並び順・カンマ区切り番号リスト・確認の4段階です。選択範囲があればその範囲、なければ現在のフレーム配置全体の配置可能セルを対象にします。会場の左上基準はY→X順、上向き基準はフレームを会場の上→下・左→右に並べ、各フレーム内を回転前のY→X順に進めます。対象数ぶんの1からの通し番号を初期入力し、01や文字列へ編集できます。番号数の不足・超過、空項目、80文字超の番号は適用前に検出します。確認後の適用は1回のUndo対象で、ブロック番号・フレーム番号・範囲外のセル番号を保持します。［フレームごとに繰り返す］では、各フレームの対象セルで番号リストの先頭へ戻ります。例えば2セルのフレームに「1, 2」を繰り返せます。リスト長はフレーム内の対象セル数の最大値に合わせ、小さいフレームでは先頭部分だけを使います。範囲選択時は各フレームの選択されたセルだけが対象です。確認画面にも繰り返し後の番号を表示します。ブロック別の番号リセットは今後の拡張です。

［島定義］の接続パスは配置可能セル（Area > 0）を対象にします。自動接続、補助直線の端点選択、表示・クリック判定、島の接続判定で同じ対象を使います。配置可能セルのないフレームは接続対象になりません。従来の補助直線で端点が配置未確定セルに指定されているものは保存データを保持し、描画・島判定から除外します。端点指定のない従来データは配置可能セルの自由端へ接続します。［向かい合わせ矩形］の指定と向かい合わせ判定は、従来のセル単位を維持します。

［島定義］の旗アイコンを選び、配置可能セルをクリックするとスタートを置けます。複数のセルに配置でき、同じセルを再クリックすると向きが上→右→下→左に回転します。斜線付き旗アイコンではスタートを削除できます。スタートは緑の枠・矢印と距離0で表示し、接続1本につき距離を1増やします。補助直線や離れたセル同士のフレーム内接続も1本として数え、無効化した接続と向かい合わせ矩形は経路に含めません。

向きはスタートから迷路へ入る「入口方向」です。スタートから直接進めるのは入口方向の接続だけで、それ以外の接続は出口として扱います。出口側のセルを距離1にはせず、入口から道をたどって到達した距離を表示します。例えば4セルの輪なら0→1→2→3となり、スタートのすぐ隣に出口側の距離3が並びます。入口方向に接続がなければ、そのスタートからは進めません。斜めの補助直線は変位の大きい軸で方向を判断し、同じ変位なら左右方向とします。

複数スタートがある場合は、入口方向の制約を守った最寄りからの最短距離を表示し、到達できないセルは「—」にします。内部では各セルにスタート・距離・親セルを保持し、一本道はシーケンス、分岐はツリーの集合として扱います。同距離で複数のスタートから届く場合は会場の上→左の順を優先します。スタートはフレーム配置ごとに保存・共有され、フレームの移動・回転に追従します。フレーム削除では一緒に削除され、Undo・Redoにも対応します。

［フレーム定義］の型編集で［接続を編集］を選び、配置可能セルを2つクリックすると、フレーム内の接続を追加・削除できます。1セル飛ばしなど隣接しないセルも接続できます。矢印キー＋Spaceでも端点を選べ、右クリック・Deleteで端点選択を解除します。接続線は金色で表示し、［隣接セルの接続に戻す］で従来の自動隣接接続へ戻せます。席なし・消去に変えたセルの接続は除去し、縮小で範囲外になった接続は保存時に除去します。接続未定義の従来データは隣接配置可能セルを接続し、明示的な空の接続一覧は内部接続なしを表します。定義はアプリ共通ファイルに保存し、新たに配置したフレームには接続をスナップショットとして保持します。配置済みフレームへ定義編集を遡って反映することはありません。接続は配置方向に回転し、［島定義］での表示・切替と島判定へ反映されます。フレーム同士の自動接続と向かい合わせ矩形の規則は従来どおりです。

［フレーム配置］の上部ツール列では［番地入力］の隣に、左右矢印の［番地のスワップ］ボタンを表示します。押すとスワップモードになり、Shift＋ドラッグで範囲選択後、選択範囲をドラッグして選択中チャンネルの番地だけを交換できます。［番地入力］モードでも、未選択位置からShift＋ドラッグで範囲選択、選択済みの範囲をCtrl＋ドラッグでスワップできます。Ctrl操作は入力ダイアログを開きません。選択済みの範囲内から選び直す場合はShift＋ドラッグを使います。修飾キーなしのクリックは従来どおり番地入力です。選択範囲外の配置可能セル（フレーム番号ではフレーム）を直接ドラッグすると単独で交換します。ブロック番号・セル番号は移動元と同じ相対位置に配置可能セルがある範囲を対象とし、片側だけ配置可能なセルがある場合や範囲が重なる場合は変更しません。フレーム番号は移動先の矩形に触れるフレームを選び、同数の場合に上→下・左→右順で対応付けます。同じフレームを両側に含めることはできません。空の番地も交換対象で、フレーム本体・他の番号・サークル配置は動かしません。ドラッグ中は移動先を枠表示し、Escまたはキャンバス外へのドロップで取消。ボタンを再度押すと入力へ戻ります。1回のUndoで交換前へ戻せます。
