# Desktop executable

Windows 用の実行・画面処理を担当します。ドラッグや編集コマンド、設定・プロジェクト保存などの共通処理は [Desktop.Core](../CircleSpaceCoordinator.Desktop.Core/README.md) にあります。

ジャンル配置・サークル配置では、スペースを通路や会場グリッドの外へドラッグすると、その場所へ仮置きできます。机へドラッグすれば正式な配置に戻り、同じスペース数の駒同士は仮置きとの交換もできます。複数の駒は `Ctrl` で範囲選択してから範囲をドラッグすると、通路も含めて交換できます。机と通路にまたがる配置や、柱・他の仮置きと重なる配置は受け付けません。

仮置き位置は配置案ごとに保存され、複製とアンドゥ／リドゥにも対応します。画面外にある未配置スペースは、画面端の矢印と件数で方向を表示します。下部にも仮置き件数を表示し、仮置きが残った状態ではExcelへ書き出せません。

ゲーム画面がアクティブなとき、`Ctrl + P`またはツールバー右端のカメラボタンでPNGスクリーンショットを保存できます。保存先はピクチャーフォルダー内の`CircleSpaceCoordinator/Screenshots`です。撮影成功後はシャッター音と視覚エフェクトを再生し、エフェクト自体はPNGへ含めません。

ウィンドウは通常のWindows操作でリサイズできます。ツールバーの手のひらアイコンの右隣にある「会場全体を画面内に収める」ボタンを押すと、右側の配置案パネルと上下のUIを避けて、会場全体を表示領域の中央へ収めます。画面を広げた後や、ズーム・パンで会場を見失ったときに使用します。

机配置モードの「席名を変更」ボタンを選び、机上のセルをクリックすると、そのセルのブロック名と席名を入力できます。席名は机にひも付くため、机の移動・回転にも追従し、机を削除すると一緒に削除されます。同ツールでは、`Ctrl`を押しながらドラッグして複数セルを範囲選択し、選択範囲をもう一度クリックするとブロック名・席名をまとめて上書きできます。ブロック名だけ、または席名だけを先に設定することもできます。既存値が混在する場合は、上書き前に確認します。`ア` と `10左` のような同じブロック名・席名の組が複数セルにある間は、該当する席名札を赤く表示します。席名を整えて組が一意になると通常色へ戻ります。机配置モードの配置案リストにある「色んなコピー」からは、コピー元・コピー先・コピー方法を選んで「机配置だけコピー」を実行できます。この方法では机、席名、島定義をコピーし、コピー先のサークル配置は維持します。維持できないサークル配置がある場合はコピーを中止します。

操作対象は水色の枠、選択中のものは半透明のハイライトで表示します。机配置の「机番号を変更」「机を移動」「机を削除」「机を回転」では、マウス位置の机１台全体に枠を付けます。「席名を変更」は対象セル、選択範囲内ではまとめて編集する範囲に枠を付けます。机のドラッグ中は元の机をハイライトし、移動先に水色の枠を表示します。番号未設定などの赤い警告は引き続き表示します。

机配置・ジャンル配置・サークル配置モードでは、キャンバス上で `Ctrl` を押しながら左ドラッグすると、選択中のツールや `Space` による画面移動よりも範囲選択を優先します。机配置では「席名を変更」以外のツールでも範囲選択できます。ドラッグ途中で `Ctrl` を離しても、マウスボタンを離すまでは範囲選択を続けます。

`Ctrl + S`またはツールバーのフロッピーディスクボタンで編集中のJSONを保存します。引数で開いたJSONは同じファイルへ保存します。引数なしで開く内蔵の架空サンプルは上書きせず、ドキュメントフォルダー内の`CircleSpaceCoordinator/Projects/fictional-working-copy.json`へ保存します。

`Ctrl + O`またはツールバーのフォルダーボタンで、標準ファイル選択ダイアログから別のJSONプロジェクトを開きます。読込み後の保存先は、選択したJSONへ切り替わります。

実行ファイルと同じフォルダーの`application-settings.json`へ、プロジェクト保存フォルダーと最後に開いたプロジェクトを記録します。次回起動時は最後のプロジェクトを自動的に開き、ファイルが見つからない場合は架空サンプルへ戻ります。コマンドラインでJSONを指定した場合は、その指定を優先します。

配置案一覧の日本語と評価値は、WindowsにインストールされたMeiryoを実行時にラスタライズし、再利用可能なMonoGameテクスチャとして描画します。

右側の配置案パネルにある`Duplicate`ボタンで、選択中の配置案を複製できます。参加サークルは番号付きの駒として常時表示し、未配置の駒は会場内の空きセル、収まらない場合は会場グリッドの下へ並べます。合体サークルの2駒は連結表示します。

画面右側には配置案を評価値の高い順で並べた一覧を表示します。行のバーが相対的な評価値、明るい緑が現在案です。行をクリックすると案を切り替えられます。前／次ボタンと`Tab`も評価順に移動します。ツールバーの重なった用紙＋印のボタンは現在案を「配置修正」版として複製し、新しい案を選択します。

GUI実行ファイルのプロジェクトです。`CircleSpaceCoordinator.Desktop.Windows.csproj` は、画面用の `Application`、JSON入出力の `Infrastructure`、GUI部品の `StationeryUI` を参照します。

グリッド、机のドラッグ＆ドロップ、参加者割り当て、ヒートマップ、配置案比較を担当します。評価計算そのものは `Core`、操作の調停は `Application` を利用します。

`DesktopApplication.LoadWorkspace` でJSONプロジェクトを画面用の `ProjectWorkspace` として開けます。

`VenueEditorGame` はMonoGame DesktopGLのウィンドウを開き、会場グリッド、机、ドラッグプレビューを描画します。中ボタンドラッグでパン、ホイールでズーム、左ドラッグで机を移動できます。

ツールバー先頭の机アイコンと石アイコンで、［机配置モード］と［サークル配置モード］を切り替えます。机配置モードでは会場サイズと机を編集し、サークル石を隠します。サークル配置モードでは机編集ボタンを隠し、参加サークルの石、一覧取込み、割当て、解除に必要なボタンを表示します。

両モード共通のハンドツールを選択すると、マウス左ドラッグで会場グリッド、机、石をまとめて画面内で移動できます。この操作は表示位置だけを変え、JSON内の配置座標やUndo履歴は変更しません。従来どおりマウス中ボタンドラッグでも移動できます。

現在の表示倍率と表示位置は、保存時にイベントプロジェクトへ1組だけ記録されます。配置案を切り替えても表示は変わらず、次に同じプロジェクトを開いたときにも復元されます。古いプロジェクトJSONに表示状態がない場合は、従来の初期倍率・初期位置で開きます。

サークル配置モードの取込みボタンから `.xlsx`、`.xlsm`、`.csv` を開けます。ExcelはClosedXMLで直接読み込むため、PythonおよびMicrosoft Excelは不要です。Excelではシートを選び、サークルID、サークル名、任意の必要セル数、任意の合体先サークルIDの列を対応付け、先頭100行のプレビューを確認してから取り込みます。同じサークルIDは内部IDを維持し、一覧から消えたサークルや必要セル数が変わって不整合になった割当ては解除されます。

取込みを試す場合は、架空の [きふわらべオンリー即売会_参加サークル一覧.xlsx](../examples/きふわらべオンリー即売会_参加サークル一覧.xlsx) をダウンロードして使えます。

サークル配置モードの書き出しボタンから、既存の `.xlsx` または `.xlsm` を選び、シート、ブロック番号列、席番号列、サークルID列を指定できます。選択中の配置案でサークルIDの採点位置に設定された席名を、同じサークルIDのExcel行へ書き込みます。席名未設定・未配置のサークルや、Excel内に見つからないサークルIDの行は変更しません。

サークル石をクリックするとそのサークルを選択し、割当てツールへ切り替わります。石に表示する `1..n` は人向けの石番号で、アプリの内部ID、イベントから渡される任意文字列のサークルID、サークル名とは別に扱います。

サークル配置モードでは、未配置または配置済みの石をマウス左ボタンでドラッグできます。ドラッグ中は青白い石のゴーストがカーソルへ追従し、机のセル上で離すと割当てまたは再割当てを1回のUndo対象操作として確定します。配置済みの石を机のない場所で離すと割当てを解除します。机の上だが容量不足や重複で割当てできない場合は元の配置を維持します。未配置の石とドラッグゴーストは必要セル数分の大きさで描き、合体先サークルIDで組になった石は隣接させて連結表示します。

配置済みの石を机上の別の石へドロップすると、2つのサークル配置を1回のUndo対象操作としてスワップします。必要セル数や合体サークル制約が交換先と合わない場合は交換を拒否し、両方の配置を維持します。

引数なしでは、最初にイベントプロジェクト選択画面を表示します。ここから新規作成、既存JSONの登録、複製、一覧の上下移動、一覧からの除外ができます。一覧から除外してもJSONファイル自体は削除されません。第1引数へJSONパスを渡した場合は、選択画面を省略してそのプロジェクトを開き、一覧へ登録します。

JSON読込み時は配置禁止セル、机、割当てセル、サークルIDの採点位置を色分けします。`Tab` / `Shift+Tab` で案を切替え、マウス位置の机を `E` / `Q` で右・左回転し、`Ctrl+Z` / `Ctrl+Y` でUndo/Redoできます。

エディターのタイトルバーにはアプリケーション名とイベント名を表示します。選択中の配置案、総合評価、選択中サークル、操作説明、保存やスクリーンショットの結果は画面下部のステータスバーへ表示します。

未割当てサークルは `↑` / `↓` で選択し、マウス位置の机へ `A` で割り当てます。マウス位置の割当ては `Delete` で解除できます。選択中のサークル名はウィンドウタイトルへ表示し、ログには名前やIDを出しません。

画面上部のアイコンツールバーから、前後の配置案、Undo、Redo、机の左・右回転、サークル割当て、割当て解除をクリック操作できます。ホバー中はウィンドウタイトルへ日本語の操作名を表示し、無効な操作は暗色表示にします。

机追加ツールを選んで会場セルをクリックすると、標準の2セル机を追加します。追加前はマウス位置に青白いワイヤーフレームのゴーストを表示し、実際に占有するセルと向きを確認できます。机追加モードのままツールバーの左回転・右回転ボタンを押すと、モードを解除せずにゴーストを90度回転できます（キーボードの `Q` / `E` でも同じ操作ができます）。配置禁止セル、会場外、既存机との重なりによって配置できない位置ではゴーストが赤色になります。最後に移動または回転した机の向きを記憶し、次に追加する机へ引き継ぎます。次の向きは画面下部の「次の机」欄に表示し、各机の正面側の辺には机色より少し濃い短い印を表示します。机削除ツールはクリックした机を削除しますが、サークル割当てが残る机は削除を拒否します。自動配置ボタンは配置禁止セルと既存机を避けて空き領域を2セル机で埋めます。横幅・縦幅の±ボタンで会場サイズを1セルずつ変更し、縮小で既存要素が会場外へ出る場合は拒否します。

机削除ツールを選択している間は、サークルが割り当てられていて削除できない机をグレー表示します。削除するには、先にサークル配置モードでその机の石を移動するか割当てを解除してください。他の机操作を選択している間は通常色へ戻ります。

架空サンプルは全サークルが割当て済みなので、最初は割当て（＋）が無効です。解除（×）でサークルを一つ外すと＋が有効になり、＋を選んで机セルをクリックすると再割当てできます。

GUI操作は実行ファイル横の `logs/ui-operations-*.jsonl` へ記録します。時刻、操作名、画面座標、グリッド座標、成功可否、検証コードだけを記録し、サークル名・サークルID・業務値は記録しません。`logs/` はGit対象外です。

`VenueCanvasMapper` がCoreの整数座標とStationeryUIのキャンバスセルを変換し、GUI部品DLLに計算DLLへの依存を持ち込まないようにします。

`Interaction/DeskDragController.cs` は、机のヒットテスト、ドラッグ中のプレビュー、ドロップ時の確定を扱います。ドラッグ中はプロジェクトを変更せず、正常なドロップだけをUndo履歴へ1操作として追加します。
